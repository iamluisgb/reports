# Web fonts

Self-hosted latin subsets, loaded by `styles.css` (`@font-face`) and preloaded in each page's head.

| File | Family | Licence |
|---|---|---|
| `InstrumentSerif-normal.woff2`, `InstrumentSerif-italic.woff2` | Instrument Serif | SIL Open Font License 1.1 |
| `Geist-normal.woff2` (variable, 400–600) | Geist (Vercel) | SIL Open Font License 1.1 |
| `GeistMono-normal.woff2` (variable, 400–500) | Geist Mono (Vercel) | SIL Open Font License 1.1 |

Subsets come from Google Fonts' `latin` range. `scripts/check_design.py` keeps the total under its byte budget.
