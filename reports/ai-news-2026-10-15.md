## Papers — ArXiv

### Doc2Harness: Benchmarking LLMs on Long-Horizon Harness Engineering of Coding Agents

Agent benchmarks measure task success under a fixed harness, so nobody tests the thing that actually determines results — the scaffolding around the model. Doc2Harness makes harness construction the task: a build model receives an interface skeleton plus a development document distilled from twelve frontier harnesses and must produce a working harness, which is then frozen and driven end-to-end by scripted mock models in isolated containers. It is the first benchmark to score the engineering layer directly rather than assume it. **[coding-agents, harnesses, benchmarking]**

Sources: [arXiv](http://arxiv.org/abs/2610.20344v1)

### SpecGuardBench: Can Coding Agents Construct Reliable Validation Harnesses from Natural Language Specifications?

Passing the tests an agent was given proves little — the open question is whether agents can build their own checks that faithfully capture a specification. SpecGuardBench poses 291 tasks from 13 real repositories across 8 verification-logic types, requiring agents to construct executable validation harnesses that reject spec-violating implementations. It measures whether generated evidence is trustworthy, not merely whether code runs. **[coding-agents, verification, benchmarking]**

Sources: [arXiv](https://arxiv.org/abs/2610.16870v1)

### Maximising Transparency in Context Compaction Improves Retention of Facts and Commitments for Lightweight Coding Agents

Long coding sessions force context compaction, and the usual model-written summary silently drops facts and commitments the agent still needs — worst for the small models now running locally. Transparent-compact, built for the open-source Pi agent, is deterministic: user and assistant prose is guaranteed unchanged, and stripped information is explicitly flagged rather than paraphrased away. It targets exactly the lightweight, high-volume deployments where a lossy summary hurts most. **[context-management, coding-agents, lightweight-models]**

Sources: [arXiv](http://arxiv.org/abs/2610.20116v1)

### The Wealth of Agents: Scaling Agentic AI Across Developers

Agentic systems assume a single developer controlling every agent, which caps scale at one person's budget. This paper models multi-developer agentic systems where specialists' agents compose: on GAIA, a population of specialists each capped at 35% accuracy reaches 70% when combined — 12 points above a median general-purpose system built with several times each specialist's budget. Composition, not capability per agent, does the work. **[multi-agent, orchestration, scaling]**

Sources: [arXiv](http://arxiv.org/abs/2610.20518v1)

### AgentCIScope: Grounded Contextual Integrity Evaluation for LLM Agents

Model-level privacy benchmarks miss the real risk: agents with tool access moving sensitive data across email, documents and calendars in ways that violate context-specific disclosure norms. AgentCIScope turns public and synthetic privacy cases into executable multi-step agent tasks in realistic application environments and scores whether the resulting information flows preserve contextual integrity. It evaluates the flows, not the model's refusal behaviour. **[privacy, agents, benchmarking]**

Sources: [arXiv](http://arxiv.org/abs/2610.19158v1)

### RuleTrek: Benchmarking Agentic Rule Reasoning in Complex Scenarios

Existing rule-reasoning benchmarks hand the model a handful of tidy facts, which flatters real performance where domain rules are scattered across many files. RuleTrek builds multi-domain scenarios from structured rule graphs, composing sub-scenarios incrementally while guaranteeing consistency and solvability, and tests rule identification, application and conflict handling in interactive workspaces. Closer to the compliance-shaped mess agents actually face. **[agents, rule-reasoning, benchmarking]**

Sources: [arXiv](http://arxiv.org/abs/2610.19698v1)

## Why It Matters

-   The harness has become the object of study, not the backdrop. Doc2Harness scores harness construction directly; SpecGuardBench asks whether agents can build their own trustworthy evidence; OpenCode 2.0 pulling 493 points in hours says the market already agrees the scaffolding is the product. If you are still differentiating on the model behind your agent, you are competing on the commodity layer.

-   The security story converges from two directions. CSO Online's reporting locates the 'rogue agent' incidents in skipped containment and monitoring — plumbing, not intent — and AgentCIScope formalises the same point for privacy: what matters is the information flow an agent produces, not whether the model can recite a policy. Neither problem is fixed by a better system prompt; both need the same instrumentation you would put around any privileged service.

-   Small models are arriving with their own constraints attached. Liquid AI's 2B-active on-device agent and transparent-compact both assume capable-but-light models in long sessions, which makes context discipline — what survives compaction, what gets retrieved — the binding engineering constraint. And the Wealth of Agents result (35% specialists composing to 70% on GAIA) suggests the other lever is orchestration across cheap agents rather than a bigger single model. The capability curve is flattening into an systems-engineering problem, and the papers this week are the measurement apparatus for it.
