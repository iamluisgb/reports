## Papers — ArXiv

### Adaptive Skill Granularity for Coding Agents

Coding agents face a runtime control problem prior skill work ignores: the same task can go through primitive tool calls, a macro skill, or a macro that fails and needs micro-level recovery. This paper treats granularity as an action-abstraction policy conditioned on task structure and execution state, pairing a feature-based controller with a finite-state recovery executor. Evaluated under a deterministic protocol with verifier-defined success, cost and process metrics. **[coding-agents, skills, action-abstraction]**

Sources: [arXiv](http://arxiv.org/abs/2610.31461v1)

### ColaBench: Evaluating Memory-Guided Knowledge Acquisition in Personal Agents

A personal agent can retrieve the right document and still give the wrong answer if it ignores the user's circumstances — memory recall and knowledge application are usually benchmarked separately. ColaBench joins them: 349 tasks across 10 profiles over a 13,033-document knowledge base, with an Evidence Graph tying personal conditions to disclosures and prior document exposure. A concrete target for anyone building memory into user-facing agents. **[personal-agents, memory, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2610.30989v1)

### DConstrain: Compiling Context-Parameterized Transitions for Diffusion Language Model Constrained Decoding

Diffusion language models decode tokens in parallel, so individually valid tokens can jointly violate a schema; exact grammar-constrained inference blows up because parser state explodes exponentially. DConstrain compiles schemas into context-parameterized transition programs, tracking stacks and field histories symbolically at runtime. Arbitrary property order without offline enumeration — the missing constrained-decoding primitive for DLMs. **[diffusion-lms, constrained-decoding, structured-output]**

Sources: [arXiv](http://arxiv.org/abs/2610.30920v1)

### ProQuant: Preserving Expert Quality over Quantity in Ultra-Low-Bit Quantization of Mixture-of-Eeexperts Models

MoE models cut compute via sparse activation but their storage bill stays large, and existing mixed-precision PTQ degrades generation quality at tight bit budgets. ProQuant diagnoses two failure modes — cross-layer error propagation ignored at extreme precision, and router fine-tuning causing routing drift — then jointly optimises expert pruning and bit-width allocation. Higher-precision experts substitute for degraded ones rather than every expert suffering equally. **[quantization, moe, efficiency]**

Sources: [arXiv](http://arxiv.org/abs/2610.30779v1)

### Benchmarking the Quantum Leap: Auditing LLM Evaluation for Quantum Code Generation

Quantum code-generation benchmarks disagree because task composition, scoring and failure handling differ, and nobody has audited the evaluators themselves. This audit runs 15 models over five suites (530 tasks) plus a new 96-task benchmark, with bootstrap CIs and multiplicity-corrected comparisons. QiskitHumanEval-Standard is saturated at 98.7% pass@1 while the Hard variant retains headroom at 63.8%; removing evaluator checks for unspecified quantities materially inflates scores. **[evaluation, code-generation, benchmarks]**

Sources: [arXiv](http://arxiv.org/abs/2610.28678v1)

### Transformers as Generic Deep Neural Networks: Exact Compilation and the Cost of Removing Activation-Activation Products

Transformers get dedicated silicon and bespoke quantization, but this paper proves every Transformer block — attention, LayerNorm, GELU MLP — compiles exactly into a generic DNN of affine maps, routing, square, sigmoid and inverse square root. The catch: dropping activation-activation products costs at least N² extra scalar nonlinear evaluations per head for dense scores. A direct argument for keeping elementwise products in NPU instruction sets. **[architecture, compilation, hardware]**

Sources: [arXiv](http://arxiv.org/abs/2610.28958v1)

## Why It Matters

-   The frontier is now priced, not just ranked. Moonshot ships a Highspeed tier alongside K3.1 Pro on day one; ThinkingCap reports 39-69% fewer thinking tokens at flat accuracy; ProQuant attacks MoE storage at ultra-low bits. Three independent groups converged on the same conclusion — capability is no longer the binding constraint, cost per token is — and the engineering response is arriving at every layer of the stack: token budget, precision, serving tier.

-   Evaluation is the soft infrastructure underneath all of it, and it is creaking. The quantum audit shows evaluator design alone moves scores enough to flip rankings; ClickBench pulled a pgrust entry for per-query caching; the ModelCompare thread documents convergent model answers that trace to shared training data rather than anything alignment-shaped. If you are picking a model off a leaderboard this quarter, the number you read is a function of harness choices as much as model quality — and the harness choices are rarely disclosed.

-   Agent engineering is graduating from prompting to control theory. Adaptive Skill Granularity treats macro-versus-micro execution as a policy with a recovery state machine; ColaBench benchmarks whether memory actually changes the answer, not just whether it is recalled; DConstrain supplies the constrained-decoding machinery diffusion LLMs will need the moment they matter. The papers cluster where the practitioner money already went — Corgi, the multiplexer thread, the OpenAI-starts-100-companies debate — on the harness as the product, with the model as a replaceable component inside it.
