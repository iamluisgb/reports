Papers — ArXiv CS.AI
01
Causal Memory Policy: Making Memory Utility Identifiable by Intervening on Retrieval
Memory-augmented LLMs decide what to keep by estimating each memory's effect on task performance, but those estimates only ever see retrieved memories — a memory that is never retrieved produces identical outcomes under any store-level intervention, so its utility is unidentified. CMP restores identification by intervening on retrieval itself, reserving fixed context slots for memories sampled with known propensities and estimating utility with self-normalised inverse propensity weighting under a balanced assignment design. The paper proves the causal factorisation of memory utility through retrieval, plus unbiasedness and exact variance for the estimator. agent memory, causal inference, retrieval
arXiv
02
Mimir: Physics-Grounded LLM Agents for Long-Horizon Irrigation Control
LLM agents are mostly validated on episodic tasks where failures reset, but long-running physical control compounds errors across decisions and demands improvement without ever rewriting the physics that keep execution safe. Mimir runs irrigation across full growing seasons on two repair timescales — a deterministic simulator numerically checks and revises each LLM proposal before execution, while a slower recurrent loop lets the agent learn from experience. The contribution is the harness: the model proposes, the physics disposes. llm agents, long-horizon control, verification

03
OpenMTB-Audit
Safety evaluation for LLMs in molecular tumour boards must separate genuinely unsupported recommendations from evidence-supported options that need oncologist review anyway — incomplete information, poor performance status, clinical caveats. Across 500 synthetic non-small-cell lung cancer cases, five adversarial error categories and eight LLM configurations, every configuration lost the Partially Supported label in 83.3–100% of true cases, buying high aggregate safety scores through label collapse. The lesson travels beyond oncology: an eval that rewards refusal measures compliance, not judgement. over-refusal, safety evaluation, oncology
arXiv
04
TopK-Guided
Training-free activation sparsity has been a choice between two flaws: threshold methods such as TEAL adapt sparsity per token but cannot control what they realise, while TopK methods such as WINA hit a fixed target with the same budget for every token and every block. TopK-Guided adds bounded token-level adaptation and sensitivity-aware per-block budget allocation, still with no training, and consistently improves perplexity and downstream accuracy over both across Llama-2 and Llama-3. Block sensitivity differs enough that a uniform budget is wasted compute. activation sparsity, inference efficiency, training-free
arXiv
05
Decision Titan
Long-term dependencies in sequential decision-making pit RNNs' vanishing gradients against transformers' quadratic attention, and test-time training offers a third route — episodic memory written into network parameters by gradient descent at test time. Decision Titan is the first application to offline RL, grafting TTT layers onto a Decision Transformer, and goes beyond returns to analyse what the parametric memory actually retains. offline reinforcement learning, test-time training, memory

Why It Matters
▸ Three separate takes on agent memory landed today and they converge: the value of stored state depends on future queries nobody can predict, so compressing eagerly discards the wrong things. The context-graph paper argues compaction should preserve structure rather than prose, and Causal Memory Policy makes that argument measurable — utility is unidentifiable unless retrieval is randomised, so any retention policy tuned on retrieved memories alone is fitting an artefact of its own retriever. Decision Titan moves the problem into the weights, writing episodic memory into parameters at test time. If you build agents, the actionable move is instrumenting retrieval propensities before buying another summariser.
▸ The most durable results today are negative — proofs that a trusted proxy measures something other than what it claims. OpenMTB-Audit found all eight LLM configurations collapsing the 'partially supported' label in 83.3–100% of tumour-board cases, so their strong safety scores were rewarding refusal rather than judgement. The knowledge-graph attack recovers edges that publishers deleted before release, voiding redaction as practised, and the Utah ruling concedes that age verification through a VPN is a technical impossibility. Cloudflare's OHTTP gateway is the constructive version of the same lesson — don't audit the proxy, remove the identity from the path entirely.
▸ The other thread is the collapsing cost of the proposer itself: training-free per-block sparsity, a local runtime from the Redis author, a flash-tier GLM carrying a month of real Wagtail work, and a budget Stratego system that beat the best human player. Capability per dollar is no longer the constraint, which moves the engineering elsewhere. Mimir spends its design on the deterministic checker around the model rather than the model — Greg Kroah-Hartman's talk is the same position from the maintainer's seat. The scarce resources are memory and the gates around the model, not parameters.
