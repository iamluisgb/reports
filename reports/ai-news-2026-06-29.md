## Papers — ArXiv CS.AI

### Seven Security Challenges That Must be Solved in Cross-domain Multi-agent LLM Systems

LLMs are evolving into autonomous agents cooperating across organizational boundaries. This paper identifies seven critical security challenges in cross-domain multi-agent systems: data leakage, adversarial manipulation, trust delegation, and more. **[security, multi-agent, LLM]**

Sources: [arXiv](https://arxiv.org/abs/2505.23847)

### Just Ask: Curious Code Agents Reveal System Prompts in Frontier LLMs

Autonomous code agents can extract system prompts from frontier LLMs through agentic interaction — a previously unrecognized security risk that expands the LLM attack surface. **[security, agents, prompt-injection]**

Sources: [arXiv](https://arxiv.org/abs/2601.21233)

### Hierarchical Control in Multi-Agent Games: LLM-based Planning and RL Execution

Proposes a hierarchical architecture combining LLM-based high-level planning with RL execution for multi-agent coordination — addressing sparse rewards and large state-action spaces. **[multi-agent, RL, planning]**

Sources: [arXiv](https://arxiv.org/abs/2606.20014)

### When Does Personality Composition Matter for Multi-Agent LLM Teams?

Personality prompting shapes LLM communication but task effects depend on structure: low agreeableness hurts collaboration and bargaining but not coding. Implications for multi-agent system design. **[multi-agent, personality, LLM]**

Sources: [arXiv](https://arxiv.org/abs/2606.27443)

### Contagion Networks: Evaluator Preference Propagation in Multi-Agent LLM Systems

When LLMs serve as evaluators in multi-agent systems, their strategy preferences propagate through the network. Introduces a formal framework for measuring evaluator preference contagion. **[multi-agent, evaluation, LLM]**

Sources: [arXiv](https://arxiv.org/abs/2606.20493)

### ToolPrivacyBench: Benchmarking Purpose-Bound Privacy in Tool-Using LLM Agents

New benchmark evaluating privacy in tool-using LLM agents — conventional benchmarks miss privacy violations during multi-step tool execution. **[privacy, agents, benchmark]**

Sources: [arXiv](https://arxiv.org/abs/2606.28061)

### Grounded Iterative Language Planning: How Parameterized World Models Reduce Hallucination

Compares agent-based vs parameterized world models for LLM agents. Parameterized models reduce hallucination propagation in long-horizon planning tasks. **[agents, world-models, planning]**

Sources: [arXiv](https://arxiv.org/abs/2606.27806)

### LiveClawBench: Benchmarking LLM Agents on Complex, Real-World Assistant Tasks

Evaluates personal assistants extending LLM agents from isolated tool use to open-ended, stateful environments. Benchmarks must be faithful to real assistant task distributions. **[agents, benchmark, assistant]**

Sources: [arXiv](https://arxiv.org/abs/2604.13072)
