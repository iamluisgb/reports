## Headlines

### OpenAI Prepares to File for IPO in Coming Weeks

OpenAI is preparing to file confidentially for an initial public offering, marking a major transition from nonprofit research lab to public company. The move follows massive revenue growth from ChatGPT Enterprise and API sales.

Sources: [NYT](https://www.nytimes.com/2026/05/20/technology/openai-ipo.html) · [OpenAI News](https://openai.com/news/)

### GitHub Confirms Breach of 3,800 Repos via Malicious VSCode Extension

A GitHub employee installed a trojanized Nx Console VSCode extension, leading to exfiltration of ~3,800 internal repositories. Threat actor TeamPCP demands $50K+ for the data. Prior supply chain attacks by the same group impacted Trivy (1,000+ orgs), Checkmarx, and LiteLLM.

Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/github-confirms-breach-of-3-800-repos-via-malicious-vscode-extension/) · [CyberSecurityNews](https://cybersecuritynews.com/github-source-code-breach/)

### Microsoft Starts Canceling Claude Code Licenses Across E+D Teams

Microsoft is winding down Claude Code licenses across Windows, M365, Outlook, Teams, and Surface by June 30. Claude Code proved extremely popular internally — undermining GitHub Copilot CLI adoption. Engineers are being pushed to migrate to Copilot CLI.

Sources: [The Verge](https://www.theverge.com/tech/930447/microsoft-claude-code-discontinued-notepad) · [HN Discussion](https://news.ycombinator.com/item?id=48209112)

## Why It Matters

-   **Supply chain attacks hit developer tools directly.** The GitHub/VSCode breach demonstrates what happens when the tools we trust to build software become the attack vector. TeamPCP's cross-ecosystem reach (GitHub, PyPI, npm, Docker) means this isn't a one-off — it's a structural shift. Staged publishing on npm is the right response, but adoption will be slow.

-   **Enterprise AI economics are getting real.** Microsoft canceling Claude Code licenses while simultaneously finding AI more expensive than humans tells a story: the AI cost curve isn't following Moore's Law yet. The move to on-prem (OpenAI+Dell) and the IPO signal that the industry is moving from "experiment" to "optimize P&L."

-   **MCP infrastructure is being built in real time.** Anthropic's acquisition of Stainless is a bet on the Model Context Protocol becoming the standard connector layer between LLMs and external tools. Paired with npm's security controls and the broader push toward agent-native workflows, the plumbing for agent ecosystems is rapidly taking shape.
