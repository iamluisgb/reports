Papers — ArXiv
01
EvoX: Rethinking the Agent Harness as a Runtime Policy
LLM agents often fail between a plausible decision and a completed tool call — mismatched arguments, interrupted workflows, unsupported completion claims. EvoX recasts the harness as an operational policy in Rust, with action realisation, execution continuity and outcome grounding, and introduces Contrast to evaluate harnesses without suppressing native behaviours across five benchmarks and six foundation models. The paper's claim is architectural rather than a single score: runtime control is part of the policy, not plumbing. [agent-harness, runtime-policy, tool-use]
arXiv
02
Contain, Conform, Compare: A Red-Teamed Evaluation Kit for Small Coding Agents
Hosted coding-agent scores are noisy and opaque, so teams need local evaluators that match the scorer while safely running agent-written code. drydock-eval runs Gemma 4 E4B at about 250 runs per hour on one RTX 5090, contains each job in a fresh networkless container that passed 200 scripted escape tests, and adds eight configuration checks plus paired statistics clustered by repository. The extended record releases 9,660 agent-run rows, 2,494 grading controls and 72 serving measurements. [coding-agents, evaluation, sandboxing]
arXiv
03
AgentScript-Eval: Benchmarking LLMs and Agents for Code Generation in an Enterprise DSL
Enterprise DSLs are common but absent from public pretraining, so general-purpose code-generation benchmarks say little about agent authoring in platforms such as Salesforce Agentforce. AgentScript-Eval grades 100 real AgentScript tasks — authoring from specification, debugging and optimisation — and evaluates five models zero-shot. The contribution is an execution-graded test of a non-public, declarative language rather than another Python leaderboard. [enterprise-dsl, code-generation, agents]
arXiv
04
AstroMemBench: A Benchmark for Memory Systems in Embodied Spacecraft Agents
Long-lived spacecraft agents must use operational history under delay, power limits and safety constraints, but memory benchmarks rarely encode those conditions. AstroMemBench maps them to 16 memory subchallenges, 140 templates and 2,240 instances across nine tasks in planetary surface, on-orbit servicing and deep-space settings, with a deterministic scorer for completion, state change, safety and resources. Nine ablation conditions show the benchmark is sensitive to history recovery and memory-system design. [memory, embodied-agents, benchmark]
arXiv
05
Can MLLMs Reason over Surround-View Driving Videos? A Multi-View Autonomous Driving QA Benchmark
MLLM driving evaluations are mostly front-view, leaving surround-view spatio-temporal reasoning untested. MVDriveBench synchronises multi-view video inputs and defines 12 QA categories from low-level perception to driving decisions, with reasoning-chain-oriented evaluation. It is a measurement paper for a capability that real driving needs but front-camera benchmarks miss. [multimodal, driving, benchmark]

Why It Matters
▸ The agent-engineering papers converge on the same claim: capability is not the only bottleneck. EvoX treats the harness as runtime policy, drydock-eval measures containment and scorer conformance, and AgentScript-Eval tests code generation in a private enterprise DSL — all three put engineering controls ahead of another model point. That is a more useful reading of the day than the 'AI solved coding' argument, which measures shipped software rather than constrained agent execution.
▸ Benchmarks are moving from static question answering to stateful, safety-constrained operation. AstroMemBench scores memory recovery under spacecraft constraints, while MVDriveBench forces surround-view spatio-temporal reasoning rather than front-camera guessing. Both are attempts to make evaluation match deployment conditions — the same discipline missing when generated apps on Lovable exposed passport scans and 200,000 private messages.
▸ Release and disclosure discipline remains a separate failure surface. Project Zero's restored 90-day deadline and Italy's $887M Meta fine are reminders that security and privacy are governed by process, not model quality. The coding-agent papers are strongest when they borrow that posture: networkless containers, 200 escape tests and paired statistics are the agent equivalent of a disclosure deadline — an external constraint that makes claims checkable.
