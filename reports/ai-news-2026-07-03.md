## 📄 Papers — ArXiv CS.AI / CS.CL

### Safeguarding LLM Agents from Misalignment through Provenance Analysis

When an agent's proposed tool invocation deviates from the user's intent (misalignment), provenance analysis traces back through the agent's reasoning chain to detect and prevent harmful actions before execution.

Sources: [arXiv](http://arxiv.org/abs/2607.01236v1)

### Kara: Efficient Reasoning LLM Serving via Sliding-Window KV Cache Compression

Reasoning LLMs generate long chain-of-thought accumulating massive KV cache. Kara compresses KV cache via sliding-window approach, reducing decoding latency and improving throughput for serving reasoning models at scale.

Sources: [arXiv](http://arxiv.org/abs/2607.01237v1)

### Auto-FL-Research: Agentic Search for Federated Learning Algorithms

Constrained coding-agent workflow for FL algorithmic recipe search. Agents propose and implement candidate training algorithms including server aggregation rules, client update schedules, and local objectives.

Sources: [arXiv](http://arxiv.org/abs/2607.01366v1)

### Agent4cs: Multi-agent System for Code Summarization in Large Hierarchical Codebases

Multi-agent approach to code summarization in large, complex codebases with obfuscated structures and incomplete documentation. Outperforms single-model approaches on hierarchical code understanding tasks.

Sources: [arXiv](http://arxiv.org/abs/2607.01425v1)

### When Should Service Agents Reconsider? Difficulty-Routed Control

Autonomous customer-service agents shifting from conversational to operational execution roles. Proposes difficulty-routed control to determine when agents should reconsider their actions before executing backend writes.

Sources: [arXiv](http://arxiv.org/abs/2607.01426v1)

### World Feedback for Clinical Agents: Diagnosing RL in FHIR Environments

Clinical protocol-execution tasks (lab values, thresholds, FHIR orders) as candidates for RL from world feedback. Clinical SMEs encode decision logic into verifiers for autonomous clinical agent training.

Sources: [arXiv](http://arxiv.org/abs/2607.01470v1)

### Procedural Memory Distillation: Online Reflection for Self-Improving LMs

Extends RLVR with procedural memory distillation — agents learn from richer procedural information beyond episode-level signal, enabling continuous self-improvement through online reflection mechanisms.

Sources: [arXiv](http://arxiv.org/abs/2607.01480v1)
