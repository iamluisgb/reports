## Papers — ArXiv CS.AI

### Argus: A General-Purpose Agentic Runtime for Long-Horizon Reasoning

Persistent, self-evolving runtime where Manager, Planner, Engineer and Reviewer persist evidence and pivot on failure — attacking the long-horizon execution problem head-on. **[agents]**

Sources: [arXiv](https://arxiv.org/abs/2608.05144)

### OctoLong: Mid-Training On Cross-Repository Code Contexts Enhances Long-Context Modeling

Long-context corpora are finite and repo-dominated; OctoLong mid-trains on cross-repository code contexts to push long-context modeling beyond books and single repos. **[llm]**

Sources: [arXiv](https://arxiv.org/abs/2608.05141)

### ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment

Existing agent training treats every step uniformly in SFT/RL; ABSeeker backtracks from the answer to assign credit — a fix for the credit assignment problem in search agents. **[agents]**

Sources: [arXiv](https://arxiv.org/abs/2608.05102)

### Hierarchical Graph Memory for LLM Agents with Path-level Localization and Rewrite

Graph memory for long-term agents is often flat and unmaintainable; this paper adds path-level localization + rewrite so memories can be efficiently updated as facts and feedback arrive. **[agents · memory]**

Sources: [arXiv](https://arxiv.org/abs/2608.05095)

### Item Response Theory for AI Safety

Safety benchmarks duplicate, correlate, and are sandbaggable; IRT offers a way to model latent safety ability from item-level responses instead of trusting aggregate scores. **[safety · eval]**

Sources: [arXiv](https://arxiv.org/abs/2608.05086)

### Chained Recursive Language Models for Multi-Iteration Reasoning

Single inference trajectories must explore, store state and verify simultaneously; chained recursive LMs decompose multi-iteration reasoning across iterations. **[llm · reasoning]**

Sources: [arXiv](https://arxiv.org/abs/2608.05124)

## Why It Matters

-   Gateways are becoming the control plane for agents: Unity AI Gateway brings governance, caching and guardrails to AI endpoints, and Databricks closing Panther pushes security detection onto the same lakehouse. Expect the AI platform layer to consolidate around trust and access.

-   Today's ArXiv papers attack the same frontier from the research side — long-horizon execution (Argus, ABSeeker), long-context code (OctoLong) and maintainable agent memory (Hierarchical Graph Memory) — while LFM2.5 points to running those agents on small, self-hosted models.
