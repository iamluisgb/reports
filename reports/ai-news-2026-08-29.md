## Papers — ArXiv CS.AI

### When to Adapt: Conditional Memory Adapters for Retention-Preserving Domain Specialization

Engram Adapter turns pretraining-time conditional memory into a post-hoc adapter for frozen LLMs, gating residual injection so in-domain gains do not cost out-of-domain performance. Tested on Qwen3-4B/8B against reasoning, translation, code, and legal benchmarks. **[adapters, fine-tuning, domain-adaptation]**

Sources: [arXiv](http://arxiv.org/abs/2608.29327v1)

### Learning Simple Test-Time Environments for LLM Web Agents

TTED has agents decompose complex environment observations into sub-modules, then adapt label-free during inference; gains from simpler environments transfer to realistic web benchmarks. **[web-agents, test-time-adaptation, eval]**

Sources: [arXiv](http://arxiv.org/abs/2608.29305v1)

### TRACER: Per-Tool Context Retention for LLM Agents via Consequence-Attributed Reinforcement Learning

TRACER treats context compression as a sequential per-tool decision: a REINFORCE policy sets retention ratios under an objective that weighs task success, token spend, and tool re-invocations. **[agents, context-compression, RL]**

Sources: [arXiv](http://arxiv.org/abs/2608.29363v1)

### LiteSearch-VL: Small Multimodal Search Agents via Trajectory Distillation and Synthetic Step-DPO

A low-compute recipe distills released agent trajectories into Qwen3-VL-2B and 4B backbones with LoRA and GPT-5-generated step-level preferences, probing what actually transfers to small multimodal search agents. **[multimodal, agents, distillation]**

Sources: [arXiv](http://arxiv.org/abs/2608.29357v1)

### AlgoWorlds: Benchmarking Tool Use for Global Optimization in Algorithmic Worlds

The benchmark turns combinatorial optimization problems into partially observed environments with verifiable global optima, testing whether agents turn tool-gathered information into decisions that are optimal, not merely feasible. **[tool-use, optimization, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2608.29397v1)
