## Papers — ArXiv CS.AI

### Context-Aware RL for Agentic and Multimodal LLMs

Proposes ContextRL, an RL framework that trains LLMs to identify decisive evidence within long contexts (tool traces, images). Addresses the failure mode where models miss a single critical line in complex multi-turn agent tasks. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.17053)

### ExpRL: Exploratory RL for LLM Mid-Training

Introduces exploratory RL as a mid-training phase that improves coverage before fine-tuning. Shows that models primed through exploration before sparse-reward RL achieve significantly better reasoning performance. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.17024)

### DeepRubric: Evidence-Tree Rubric Supervision for Deep Research Agents

RL with rubric-based rewards optimizes deep research agents against checkable criteria. Translates report quality dimensions into structured evidence trees for verifiable reward signals during training. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.17029)

### Agent Trajectories as Programs: Fingerprinting Coding-Agent Behavior

Introduces methods for comparing agents procedurally across different contexts. Fingerprints coding agents by their program-level trajectories rather than just benchmark scores — reveals how agents actually solve problems. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.16988)

### TokenPilot: Cache-Efficient Context Management for LLM Agents

Cache-efficient context management for LLM agents in long-horizon sessions. Combines text pruning with dynamic memory eviction to minimize token footprints while maintaining task performance. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.17016)

### KVEraser: Steering KV Cache for Efficient Localized Context Erasing

Tackles post-hoc context erasing over the KV cache where local edits have global consequences. Essential for privacy-sensitive agent applications requiring selective memory removal. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.17034)
