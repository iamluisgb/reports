## Papers — ArXiv CS.AI

### Steering Geometry: Validating Human Value Geometry in LLM Steering Space

A 26K-sample benchmark tests whether activation-steering vectors encode theory-specified human-value structure; distribution-driven methods recover the expected topology, behavior-centric ones do not. **[steering, alignment, eval]**

Sources: [arXiv](http://arxiv.org/abs/2609.06289v1)

### SWE-Test: Benchmarking LLM Vulnerability Discovery via Input Prediction

A benchmark recasts vulnerability discovery as input prediction against fuzzing-mined branches in 22 real C/C++ programs; constraint inference, not navigation, dominates failure. **[agents, security, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2609.06229v1)

### Substrate-Portable Execution for Production LLM Workflows

Amazon's Rufus team separates workflow definition from runtime, compiling one typed dataflow graph to streaming, durable orchestration, or Flink batch with no workflow code changes. **[agents, inference, infrastructure]**

Sources: [arXiv](http://arxiv.org/abs/2609.06128v1)

### Beyond the Flag: Clinical Framing Closes the Moderation Gap in Suicide Risk Measurement

On 516 psychiatrist-rated posts, vendor moderation APIs separate high- from low-risk well but measure severity poorly; clinical framing in the prompt recovers much of the gap. **[moderation, safety, eval]**

Sources: [arXiv](http://arxiv.org/abs/2609.06263v1)

### VDiff-Bench: A Challenging Benchmark for Fine-Grained Image Difference Identification

1,756 four-way questions over image pairs probe fine-grained change detection; MLLMs handle semantic changes but collapse on noise and texture, often declaring no difference. **[multimodal, vision, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2609.06245v1)
