## Papers — ArXiv CS.AI

### ScholarCatalyst: A Benchmark for Retrieving Papers That Inspire New Research

The paper attacks the problem of retrieving prior work that actually inspires a new research project, not merely work that is topically similar. It uses 184 lead authors of 207 recent computer science papers to label candidates that did or could have advanced their project, each with a rationale, and builds a retrieval task from literature available when the project began. Agentic search does no better than embedding retrieval, scoring 0.42 against 0.40. **[retrieval, benchmarks, research-agents]**

Sources: [arXiv](http://arxiv.org/abs/2610.02202v1)

### Code Owns the Simulation, Jev Owns the Evaluation

Judgment models such as Jev return a probability for each described option in one call, which makes them attractive as an agent's action-selection layer, but it is unclear which decisions they can be trusted with. The paper tests Jev on reflection tests, one-shot matrix games, ALFWorld and robot control. It finds a sharp boundary: Jev solves 99% of the counterintuitive Cognitive Reflection Test questions, yet fails when the right option depends on simulation—the opponent's action or the subgoal that must come first—and plays games as if a rational opponent acted at random. **[decision-models, evaluation, agents]**

Sources: [arXiv](http://arxiv.org/abs/2610.01834v1)

### Continuous Process-Level Evaluation for Evolving Enterprise AI Agent Skills

Enterprise agent skills drift as tool APIs, models and specifications change, and final-output checks can miss process-level behavioural drift. The framework computes per-run ground truth, materialises reusable template tests and checks tool selection, arguments, execution order and database integrity with programmatic checks plus a narrowly scoped LLM judge. Across 240 trials on two skills, two specification variants, two agent harnesses and three models, 175 trials passed all applicable final numerical checks, but 162 of those (92.6%, Wilson 95% CI 87.7-95.6%) carried another evaluator-detected deviation. **[evaluation, agents, enterprise]**

Sources: [arXiv](http://arxiv.org/abs/2610.01833v1)

### RealCompanion: Benchmarking Human Understanding over Longitudinal Conversations

Companions that run for months are expected to remember what was said, infer who the person is and know when the past bears on the current message, but private records have forced benchmarks to invent the person and the questions. RealCompanion releases ten real relationships with an AI companion: 27,218 messages over up to 120 days, plus a profile, persona, chat ground truth and question set, each citing the messages it rests on. It finds the past is rarely needed and often far away—a recency window recovers the required message for 95.9% of probes—so pooled memory measures mislead. **[memory, benchmarks, dialogue]**

Sources: [arXiv](http://arxiv.org/abs/2610.01780v1)

### Agents Are Systems, Not Models: Rethinking Agentic Evaluation

Agent evaluations report cost, consistency and robustness, yet usually treat the agent as fixed rather than as a configurable system. This paper varies five parts of configuration—task information, reasoning, self-verification, time budget and backbone model—on four scientific tasks where a coding agent must find and correctly operate a published specialist model. It finds substantial run-to-run variability: about 54% of outcome variance comes from repeating the same configuration rather than changing it. **[evaluation, agents, reproducibility]**

Sources: [arXiv](http://arxiv.org/abs/2610.01618v1)

## Why It Matters

-   The centre of gravity has moved from model releases to harnesses and evaluation. DeepSeek's Harness and Pi 1.0 top the front page, Cloudflare ships Clef for decision models and RL fine-tuning, and Figma whitelists MCP clients. The papers explain the stakes: Agents Are Systems finds about 54% of outcome variance comes from repeating a configuration, Continuous Process-Level Evaluation finds 92.6% of runs that pass final numerical checks still carry evaluator-detected process deviations, and Jev solves 99% of CRT items but fails when the right action requires simulation. Shipping an agent without process-level evaluation and configuration control is now the default way to ship a regression.

-   Memory and retrieval are the unresolved layer, not the model. Pi Durable, Context Language Models, Motif, Strata, Omnesis and the vector-database obituary all point at the same gap: teams are bolting memory onto agents before the utility of a memory can be identified or measured. RealCompanion releases 10 real relationships, 27,218 messages and up to 120 days of history, and finds a recency window recovers the required message for 95.9% of probes, so pooled memory metrics mislead. ScholarCatalyst shows retrieval from research literature remains hard: agentic search scores 0.42 against embedding retrieval's 0.40, so an agent loop does not automatically beat a good index.

-   The constraints around the agent stack are becoming operational and adversarial. arXiv's tighter rate limits hit bulk paper pulls for training and retrieval, Git 3.0's SHA-256 default is being argued as a costly migration, the Linux kernel vulnerability disclosures are tangled up with backport coverage, and the Graykey iPhone bypass shows reboot-on-inactivity is not a security boundary. The same papers imply more demand for longitudinal, real-world evaluation data—exactly the kind that arXiv limits and private-records benchmarks make scarce. Treat data access, cryptographic defaults and device state as first-class agent dependencies, not externalities.
