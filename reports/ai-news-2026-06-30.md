## Papers — ArXiv CS.AI

### ToolPrivacyBench: Benchmarking Purpose-Bound Privacy in Tool-Using LLM Agents

LLMs now invoke external tools and execute multi-step tasks, but benchmarks only measure task completion — not privacy. Introduces a framework evaluating whether agents leak sensitive data across tool calls. **[agents, privacy]**

Sources: [arXiv](https://arxiv.org/abs/2606.28061)

### LiveClawBench: Benchmarking LLM Agents on Complex, Real-World Assistant Tasks

Evaluates LLM assistants in open-ended, stateful, personalized software environments. Addresses the fidelity problem — benchmarks must match real assistant task distributions and execution environments. **[agents, benchmark]**

Sources: [arXiv](https://arxiv.org/abs/2604.13072)

### Just Ask: Curious Code Agents Reveal System Prompts in Frontier LLMs

Autonomous code agents can extract system prompts from frontier LLMs through agentic interaction — a previously unrecognized security risk that expands the attack surface beyond traditional prompt injection. **[agents, security]**

Sources: [arXiv](https://arxiv.org/abs/2601.21233)

### Hierarchical Control in Multi-Agent Games: LLM-based Planning and RL Execution

Proposes a hierarchical architecture combining LLM high-level planning with RL execution for multi-agent coordination. Tackles sparse rewards and large state-action spaces in complex environments. **[agents, RL]**

Sources: [arXiv](https://arxiv.org/abs/2606.20014)

### Grounded Iterative Language Planning: Parameterized World Models Reduce Hallucination in LLM Agents

Compares agent-based vs. parameterized world models for language agents. Parameterized models reduce hallucinated state changes that compound over multi-step planning. **[agents, hallucination]**

Sources: [arXiv](https://arxiv.org/abs/2606.27806)

### When Does Personality Composition Matter for Multi-Agent LLM Teams?

Personality prompting (agreeableness, etc.) shapes agent communication but its effect on objective task outcomes is under-explored. Tests whether personality composition in multi-agent teams affects performance. **[agents, multi-agent]**

Sources: [arXiv](https://arxiv.org/abs/2606.27443)

### Supersede: Diagnosing and Training the Memory-Update Gap in LLM Agents

LLM agents fail when facts change across sessions — user moves, prices update, plans revised. Introduces benchmarks and training methods for agents to correctly use current values and discard superseded ones. **[agents, memory]**

Sources: [arXiv](https://arxiv.org/abs/2606.27472)

### Contagion Networks: Evaluator Preference Propagation in Multi-Agent LLM Systems

When LLMs serve as evaluators in multi-agent systems, their strategy preferences propagate through the network. Formal framework for measuring how evaluator biases cascade. **[agents, evaluation]**

Sources: [arXiv](https://arxiv.org/abs/2606.20493)
