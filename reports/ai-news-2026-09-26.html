Papers — ArXiv CS.AI
01
ERRAND: Budgeted Maintenance of Agent Memory
Deployed agents inherit memory stores written before the world moved — paths close, flags flip, price bands shift — so the failure mode is staleness, not ignorance. ERRAND prices revalidation as an errand competing with the task for the same action budget, funded only when value per action clears a running wage, and repairs write versions rather than deletions. Under equal action budgets in two drifting tool-use worlds it clears every non-oracle policy on the preregistered metrics. [agent memory, staleness, action budgets]

02
PartHackBench: Certified Equal-Progress Stress Tests for Partial-Credit Tool-Agent Evaluation
Partial-credit evaluation of long-horizon agents rewards milestones that may be temporary, later reversed, or not the agent's doing. PartHackBench only compares trajectories a private certifier has matched component-wise on state predicates and attribution, then measures score inflation. Across 18 sealed held-out tasks it produced matched adversaries for 15. Historical credit carried mean inflation of .252, with attack success in 10 of 15. [evaluation, agents, attribution]

03
Breaking the Environment Wall: Evolving LLM Agent Environments for Recursive Self-Improvement
Real environments are not agent-ready: information is fragmented, mixed with conflicting versions, and drifting — enough to drop a state-of-the-art agent from 83.9% to 57.6%. Env-Rethink, built on a 27B post-trained model, adaptively maintains Collection Maps and Event Logs that organise files and contextualise cross-data relationships as the environment changes. The framing is recursive self-improvement: the agent maintains its own scaffolding instead of waiting for a human to clean the workspace. [agents, environments, long-horizon]

04
HiPACE: Hierarchical Phase-Boundary Analysis and Controlled Evaluation of Feature Absorption in Sparse Autoencoders
Feature absorption — a parent concept and its children collapsing into one shared SAE direction — has been documented empirically but never predicted. This paper derives a closed-form phase boundary, λ_c(k,α)=α²k/(k-1): above it, absorbing the parent is strictly cheaper under an L0-penalised objective than coding each child. HiPACE turns that boundary into an evaluation protocol testing whether sparse autoencoders sit on the right side of it. [interpretability, sparse autoencoders, phase transitions]

05
Fair Like Us? Auditing LLM Alignment in Resource Allocation
LLMs increasingly arbitrate scarce, indivisible resources without their judgments being tied to any fairness framework. Auditing first-person allocation decisions across a broad model set against matched human scenarios: models demand stricter fairness than humans, yet behave more self-interestedly when they hold the resource, swing on framing, and resist alignment. Why It Matters
▸ The OpenAI Hacking Face trace was reconstructed by hand, log by log — that is the tell. PartHackBench quantifies why manual audit is still the default: with unverified partial credit, mean score inflation runs to .252 and adversarial trajectories win 10 of 15 matched comparisons. Plan mode's obituary is being read as a velocity win; read it instead as deleting the last human checkpoint between reading and acting. The agent papers agree the failure surface is memory and environment, not reasoning — precisely the parts that leave the weakest trails.
▸ Flock jailed Lindsey Isaacs for 13 days on a single ALPR record, Cambridge Analytica took a decade to reach a verdict, and Anthropic's supply-chain label survived appeal. The sources file these under regulation, but they are one engineering failure: institutions treating a lone record as ground truth with no revalidation loop. ERRAND formalises the fix for agents — versioned repairs, never deletions, rechecks priced against the task they protect — and it generalises well beyond agents. git-bug and Floci are the same instinct at tooling scale: provenance stored with the artefact, tests that run without trusting the network.
▸ The Jev wave — Ollaya, a one-function wrapper, a decision model playing Pokémon Red — is doing for agent serving what Ollama did for weights: pull, run, local API. That moves behaviour onto machines no lab can patch, which makes HiPACE's closed-form collapse boundary for SAE features operationally relevant, and the fairness audit's finding — models stricter than humans yet more self-interested under framing — a warning that alignment does not travel with the weights. If you ship these agents, you own the audit trail; nothing in today's stack hands it to you.
