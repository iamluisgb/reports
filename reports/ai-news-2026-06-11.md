## Papers — ArXiv CS.AI

### TAHOE: Text-to-SQL with Automated Hint Optimization from Experience

Large Language Models (LLMs) have democratized database access through Text-to-SQL, but moving from prototypes to production remains difficult. Tahoe treats prompt optimization as a dynamic data management problem, using an error-driven hint learning pipeline across Development and Deployment to consolidate debugging traces into a structured Hint Bank. On Spider 2.0-Snow, Tahoe raises pass rate from 61.95% to 79.42% using GPT-5.5. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.12387)

### ALIGNBEAM: Inference-Time Alignment Transfer via Cross-Vocabulary Logit Mixing

Source: ArXiv CS.AI

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.12342)

### Reroute, Don't Remove: Recoverable Visual Token Routing for Vision-Language Models

Vision-language models (VLMs) project images into hundreds to thousands of visual tokens, making decoder inference expensive. Reroute replaces irreversible token removal with recoverable routing — deferred tokens bypass the stage and re-enter the candidate pool at the next routing decision. Improves grounding under aggressive token reduction while maintaining general VQA performance. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.12412)

### DIRECT: When and Where Should You Allocate Test-Time Compute in Embodied Planners?

VLMs are increasingly deployed as high-level planners for embodied agents. DIRECT is a routing framework that uses multimodal scene context to allocate compute per prompt, improving the success-cost Pareto frontier over fixed model selection. Matches or exceeds a stronger model's success rate at up to 65% lower average latency on a physical Franka arm. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.12402)

### Doc-to-Atom: Learning to Compile and Compose Memory Atoms

Long input sequences are central to document understanding and multi-step reasoning in LLMs. Doc-to-Atom (Doc2Atom) decomposes each document into semantically typed knowledge atoms, each compiled into an independent micro-LoRA adapter. A lightweight query router selects and assembles only the relevant atoms into a query-specific adapter. Outperforms Doc-to-LoRA baselines while reducing memory cost. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.12400)

### Breaking Entropy Bounds: Accelerating RL Training via MTP with Rejection Sampling

Reinforcement learning has become a key component in modern LLMs, yet the rollout stage remains the key bottleneck. Bebop presents a systematic study of MTP in LLM post-training, achieving up to 95% acceptance rates and up to 25% extra inference throughput gains across mathematical reasoning, code generation, and agentic tasks. Up to 1.8x end-to-end acceleration in async RL training. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.12370)
