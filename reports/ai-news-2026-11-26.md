## Papers — ArXiv

### How Much Do Coding Agents Over-Edit, and Why? An Empirical Study of Unneeded Edits in Repository-Level Agent Patches

Patch size alone can't tell you whether agents make unnecessary edits — you need to know which edits the tests actually require. Delta Residue Attribution replays agent trajectories, reverts each patch block, and reruns the tests to classify it. Across 7,660 resolved Copilot CLI trajectories from 18 frontier models, agent code is on average at least as necessary as developer code; the extra bulk is mostly tests (61%) and documentation (13%) on SWE-bench Verified. **[coding-agents, empirical-study, swe-bench]**

Sources: [arXiv](http://arxiv.org/abs/2611.34875v1)

### DevEx is for Humans, AX is for Agents: Measuring Context Health in Agentic Software Work

Coding agents fail on the context humans hand them, yet evaluations measure only output. The paper introduces Agent Experience, scoring session transcripts on Clarity, Actionability, Fidelity and Efficiency with an LLM rubric rater. Across 882 rated sessions, Actionability is the weak point — 59.6% of ratings at or below 3 — and Stack Overflow respondents reporting context problems were 12–28% less likely to rate AI as very useful. **[agent-experience, evaluation, developer-tools]**

Sources: [arXiv](https://arxiv.org/abs/2611.33480v1)

### Interactive Proofs as a Unified Framework for Evaluating and Leveraging Verifiable Proof Generation by LLM Agents

Benchmarks score whether an LLM answers correctly; they rarely demand evidence a third party can check. Merlin-Bench casts the agent as a prover interacting with a formal verifier under a designated protocol, testing protocol-agnostic proof construction rather than fluency in any one proof language. The automated pipeline yields 100 cases across 15 problem families. **[formal-verification, llm-agents, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2611.33676v1)

### Solve Vision with Code: Coding Agents Are Stronger Visual Reasoners Than Video Models

Video generation models are being sold as native visual reasoners — reasoning unfolding in frames rather than symbols. This paper gives the same tasks, inputs and evaluator to both media: a coding agent that renders the answer video as a program versus a video model that denoises it. On VBVR-Pro-Bench, 500 instances across five cognitive categories with symbolic ground truth, the coding agent wins. **[visual-reasoning, coding-agents, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2611.34813v1)

### Dynamic Reasoning in Next-Gen Detection and Response: An Empirical Study of LLM Triage, Reinforcement Tuning, and Adversarial Evasion

Security operations centres face a scaling problem: fleet growth halves recall at a fixed analyst alert budget, even when per-event compute costs under $0.0003 per million. Across 56 experiments on four public datasets, the paper tests twelve architectural claims about LLM triage agents, graph-based signal fusion and adversarial evasion. Rarity-weighted graph risk propagation beats GraphSAGE without any neural training. **[security, llm-triage, empirical-study]**

Sources: [arXiv](http://arxiv.org/abs/2611.33470v1)

## Why It Matters

-   Verification is the spine of the day, and the papers fall in line. Anthropic's condensed GRH formalisation landing days after the original, Clojure core yielding real bugs to Lean, and a lab — not a mathematics department — settling the Hirsch conjecture all point the same way: proof assistants are becoming an eval harness with a scoreboard. Merlin-Bench makes the general form explicit — score agents on evidence a verifier accepts, not on answers or tool fluency. If you're building evals, the checkable-artifact benchmark is where the field is heading.

-   The harness papers also dismantle a comfortable narrative. DRA's replay-and-revert measurement shows agent over-editing is mostly tests and documentation, with agent code at least as necessary as human patches — 'agents thrash' doesn't survive contact with attribution. The AX paper completes the picture from the other side: output-only evals miss what actually determines outcomes, namely the context you feed the agent, where Actionability is the weakest dimension by a wide margin. Agent engineering is converging on measurement engineering, and the teams that instrument trajectories and context will out-evaluate the teams that eyeball diffs.

-   The operational layer is rotting faster than the model layer. GPT-6.2's quota cuts — 40% and 25% sooner — silently invalidate any agent budget written against last week's assumptions, and Jev was identified by latency fingerprinting because timing doesn't lie even when benchmarks do. Meanwhile a twelve-year-old pre-auth root sits in the kernel NFS server and Ubuntu's CVE turnaround is being publicly called out. Model capability gets the Aaronson thread; uptime, quotas and patch lag are where your agents actually break.
