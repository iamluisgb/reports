## Papers — ArXiv CS.AI

### Persistent Memory in Multi-Agent LLM Inference: What It Costs, What It Buys, and When You Can Tell

Multi-agent long-context systems add persistent memory tiers on the strength of ablation accuracy gains, rarely measuring the memory bill. Decomposing context across agents cuts peak KV working set to 14.3 MiB per query against 35.5 and 35.3 MiB for single-pass and RAG baselines; the persistent tier adds +0.368 MiB of peak cache and produces no detectable accuracy change (+0.015, 95% CI [-0.011, +0.046]) across eight controlled dataset pairs. The authors argue the null is structural — single-question benchmarks reset stored traces between items, so the memory has nothing to carry. **[multi-agent, kv-cache, memory]**

Sources: [arXiv](http://arxiv.org/abs/2610.07782v1)

### Confidence Reasoning Graphs: Structured Confidence Estimation for LLM Agents

Deciding whether to trust an agent's output needs calibrated confidence, but evidence is scattered across trajectory steps and frontier models expose few internal signals. CRGs estimate task success probability at inference time from a single trajectory, decomposing execution into a graph of claims rather than one holistic judgment, with no privileged model access or training data. Directly relevant to anyone shipping decision-making APIs where the consumer must know when to intervene. **[calibration, agents, inference-time]**

Sources: [arXiv](http://arxiv.org/abs/2610.07948v1)

### Agent in a Bottle: Can LLM Agents Turn Their Capabilities Into Cheap, Scalable Artifacts?

Querying a frontier model for millions of related instances is expensive; can agents autonomously distil themselves into cheaper task-specific artefacts — a trained small model, a reusable program — under fixed compute and API budgets? Across ten models and three tasks, strong zero-shot performance does not predict bottling ability: models with similar zero-shot scores diverge sharply after distillation, and 48 of 60 runs score below the lower bound. A benchmark for a capability most teams assume for free. **[distillation, cost-amortisation, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2610.08775v1)

### ParanoiaEval: Benchmarking Unnecessary Defensive Work in Agentic Coding

Coding agents over- and under-defend — refusing safe operations, skipping checks where they matter — and no benchmark judges whether risk treatment is warranted. ParanoiaEval operationalises the Avoidance-Transfer-Mitigation-Acceptance framework as 200 evidence-controlled repository task pairs, differing only in the evidence that defines the correct treatment, with metrics for violations and evidence responsiveness. First systematic handle on whether agent caution tracks actual risk. **[coding-agents, risk, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2610.08662v1)

### Transect: Retaining Observability for Long-Horizon LLM Agent Evaluations

Long-horizon agent runs produce transcripts spanning hundreds of pages from multi-agent networks, and the observability envelope — what an evaluator can reliably infer — narrows accordingly. LM-assisted analysis offers relief but grants evaluators analytical freedom that threatens reproducibility. Transect, built on Inspect Scout, pins task context and behavioural vocabulary in reusable evaluation-family configs so interpretations can be checked against the transcript. **[observability, evaluation, agents]**

Sources: [arXiv](http://arxiv.org/abs/2610.08364v1)

### How Well Do LLMs Reason with Noisy Evidence? An Active Visual Reasoning Benchmark

Active-reasoning benchmarks assume environmental feedback is trustworthy, or inject noise without a calibrated uncertainty signal. VisualNoiseQA forces a text-only LLM to solve VQA problems by interrogating a stochastic VLM sensor, exposing empirical uncertainty via self-consistency so the reasoner can choose what to probe next and when to stop. Construction is automatic and scalable from existing datasets. **[active-reasoning, uncertainty, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2610.07751v1)

## Why It Matters

-   The product news and the paper results point in opposite directions on decision-making. OpenAI shipped a Decisions API and Strands released a 2B decision model within hours of each other — decision-making is becoming a product category. But Confidence Reasoning Graphs exists precisely because calibrated confidence over an agent's work is unsolved, and it does so at inference time because frontier providers don't expose the internals you'd want. If you build on these APIs, the confidence number attached to a decision is the part to interrogate first.

-   Memory is the day's quiet null result, and it cuts against a default architecture. Decomposition across agents delivers the real win — 14.3 MiB peak KV against ~35.5 MiB baselines — while the persistent memory tier everyone bolts on buys nothing measurable on the benchmarks used to justify it. The structural critique matters more than the number: if your benchmark resets state between items, it cannot detect whether memory helps. Anyone evaluating agent memory should check their harness against this failure mode before trusting an ablation.

-   The through-line across the papers, the Jev SRE post-mortem, and the Claude Code interface critique is that verification and observability — not capability — are now the binding constraints. Bottling shows frontier models can't reliably cheapen themselves; ParanoiaEval shows agent caution doesn't track actual risk; Transect shows evaluators are losing the ability to audit long runs at all. The teams winning with agents this year will be the ones spending on judges, transcripts, and evidence-controlled evaluation rather than on the next model bump.
