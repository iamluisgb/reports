From Fixed Keys to Readable Schemas: Small Language Models for Vehicle Agent Function Calls
Compares functional tokens against schema-in-prompt for small, on-device in-vehicle models under tight memory and latency budgets: functional tokens infer compactly but cannot leave the trained function set, while schemas generalize to unseen functions. [agents, function-calling, on-device]

An Experimental Evaluation of Multimodal Prompt Injection Attacks on Agentic AI Frameworks
Introduces MMPIBench, which routes a fixed attack set through six visual carriers (OCR text, overlays, EXIF metadata, QR codes, fake interfaces, hybrids) and records how far an injected instruction travels from perception through planning to the tool call. [agents, security, prompt-injection]

Building the Harness Automatically: Self-Play in Code Distills a Text Harness for Black-Box Optimization
An agent repeatedly writes and evaluates optimizer programs, then distills that practice into a 197-word text harness that cuts Gemini Flash regret by 48% in an independent N=30 study and reaches GP-BO range on the practice family. [agents, self-play, optimization]
