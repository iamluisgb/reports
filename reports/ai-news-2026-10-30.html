Papers — ArXiv
01
When Relevant Code Is Wrong: Runtime-Aware Context for AI Coding Agents
Coding agents retrieve code and development history by semantic similarity and recency, but neither criterion establishes whether the evidence still applies under feature flags, migrations, or deployment-specific configuration. The paper defines operational context validity — a task-, deployment- and time-dependent test for whether retrieved artifacts may legitimately guide implementation — and instantiates it in CASE, an agent-agnostic framework that links repository artifacts to runtime configurations and classifies evidence as valid, invalid or unknown. The upshot: relevance-ranked retrieval actively feeds agents code that is inactive in the target deployment. [coding-agents, retrieval, software-engineering]
arXiv
02
CARI: Cross-Boundary Adversarial Runtime Injection in Coding-Agent Workflows
Coding agents now build software across ownership boundaries, where a compromised peer role can manipulate a live component — a backend, test harness, CI job — whose feedback the victim's agent must process. CARI formalises this authority mismatch: the component has legitimate diagnostic authority to report its own state, yet no authority over the victim's files, credentials or shell, and the injection exploits exactly that gap without touching the prompt, model or tools. It names a new attack surface for multi-party agent development that current sandboxing does not cover. [prompt-injection, coding-agents, security]

Why It Matters
▸ The two papers attack the same assumption from opposite ends: that the signals a coding agent consumes — retrieved history, runtime feedback — are ground truth. CASE shows relevant code can simply be dead under a feature flag; CARI shows a peer-owned test harness can lie while holding legitimate diagnostic authority. Retrieval quality and prompt hardening both miss this — the context channel itself is the vulnerability, and multi-repo agent workflows are shipping it by default.
▸ This is the same failure class as the day's security news. Orange's Edge full chain and the PHP2Shell chain that rooted 25 government servers both work through logic and authority misuse — components doing exactly what they are permitted to do, in a sequence nobody audited — not memory corruption. Agent pipelines inherit that bug class wholesale: a CI job reporting a failing test is a trusted channel, and CARI demonstrates why trust in it is unearned.
▸ The provenance thread runs wider than agents. The zombie-stats investigation and the ontology-as-checker failure mode — a wrong judge flags a correct answer and the agent obediently 'fixes' it — are CARI's attack in civilian form: a verdict's authority outranking the agent's own knowledge. Meanwhile Mistral Large 4's open weights and Gemini 4 Carbon's benchmark crowning show capability commoditising fast. The differentiator is the harness, and the harness is precisely where these unexamined trust assumptions live.
