## Papers — ArXiv CS.AI

### AgentDebugX: An Open-Source Toolkit for Failure Observability, Attribution, and Recovery in LLM Agents

Toolkit for debugging LLM agent failures where the surfacing error isn't the root cause. Observability, trace attribution, and automated recovery patterns. **[agents · observability · tool]**

Sources: [arXiv](https://arxiv.org/abs/2607.18754)

### Semantic Cooperative Games for Contribution Attribution in LLM-Based Multi-Agent Systems

Formal framework using cooperative game theory (Shapley values) to attribute output contributions across agents in multi-agent workflows. **[multi-agent · attribution]**

Sources: [arXiv](https://arxiv.org/abs/2607.18255)

### From Agent Failure Paths to Quantified Residual Risk: A Compositional Framework for Resilient Agentic AI

As agentic AI crosses trust boundaries, this paper proposes a compositional risk framework that quantifies residual risk from known failure modes — bridging the gap between mechanism description and risk quantification. **[safety · risk · agents]**

Sources: [arXiv](https://arxiv.org/abs/2607.18243)

### SAAG: Structured Agent Assessment and Grounding

Exact-match evaluation of agent tool calls obscures failure modes. SAAG distinguishes between wrong function selection, hallucinated arguments, and schema compliance without semantic correctness. **[agents · evaluation]**

Sources: [arXiv](https://arxiv.org/abs/2607.18245)

### When JSON Is Not Enough: Semantic Reliability of Schema-Constrained LLM Ordering Agents

LLMs used as transaction compilers emit schema-constrained JSON that passes validation but fails semantically. Study of ordering agents where structured output correctness ≠ task correctness. **[agents · structured-output]**

Sources: [arXiv](https://arxiv.org/abs/2607.18261)

### MUX: Continuous Reasoning via Multiplexed Tokens

Novel architecture where multiple reasoning traces are multiplexed into a single token stream, breaking the computational bottleneck of sequential chain-of-thought. **[reasoning · efficiency]**

Sources: [arXiv](https://arxiv.org/abs/2607.18264)

### Beyond Accuracy and Cost: Latency-Aware LLM Query Routing for Dynamic Workloads

Current query routers optimize for accuracy vs. cost but ignore tail latency. This paper introduces latency-aware routing for production inference workloads under dynamic request patterns. **[inference · routing]**

Sources: [arXiv](https://arxiv.org/abs/2607.18253)

### Find Before You Fine-Tune: A Diagnostic Study of Small LLMs for Cybersecurity QA

Before investing in fine-tuning small LLMs for domain-specific QA (cybersecurity), this work proposes diagnostic probes to predict adaptation success — reducing wasted fine-tuning compute. **[cybersecurity · fine-tuning]**

Sources: [arXiv](https://arxiv.org/abs/2607.18725)
