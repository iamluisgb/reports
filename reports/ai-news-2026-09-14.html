01
How Good Are Frontier Models at Physics? Expert Re-Grading Reveals Broken Evaluations and Near-Saturation of Leading Benchmarks
Frontier models score poorly on leading physics benchmarks, which clashes with what domain experts report in daily use — this paper asks which side is wrong. Faculty and graduate re-grading across six widely used benchmarks finds many marked-wrong answers are correct: grader errors, incorrect reference solutions and underspecified questions account for much of the gap. Corrected, the leading benchmarks sit near saturation — the wall was in the marking, not the models. [evaluation, physics, benchmarks]

02
K-Bench: A Benchmark for LLM Unlearning in Agentic Deployments
Unlearning benchmarks like TOFU and MUSE certify forgetting from the model's final answer — a refusal counts as forgotten. K-Bench deploys the model as a ReAct agent and inspects six channels, including chain-of-thought, tool calls and tool observations, placing the secret in exactly one of three sources: weights, prompt or retrieval store. Clearing the answer channel does not make the secret unrecoverable — it resurfaces wherever the agent leaks, and the benchmark scores each source separately while requiring the agent stays usable. [unlearning, agents, privacy]

03
GTA: Graph Theory Agent and Benchmark for Algorithmic Graph Reasoning
LLMs are asked to run multi-step graph algorithms, but existing evals use small graphs and score generated code rather than reasoning over the structure itself. GT Bench covers 24 classical problems across 44 task-structure settings — 100,000+ examples in four representations from natural language to adjacency matrix. Across eight models, accuracy hinges on input representation, the best representation shifts with density, size and topology, and the sensitivity persists, attenuated, in the strongest reasoning models. [benchmarks, graph-reasoning, input-representation]

04
Beyond Vector Similarity: Hierarchical Context-Aware Graph RAG vs Standard RAG in Enterprise Code Migration
Vector-similarity RAG fetches isolated chunks that sever inheritance chains when LLMs translate monoliths to microservices — hence high compilation failure rates. HCRG extracts ASTs with tree-sitter, maps architectural edges into a property graph and serialises it parent-first into a context cache for topological code translation. The evaluation lesson matters as much as the pipeline: CodeBLEU scores both approaches identically at 91%, so the authors built a 7-metric software engineering framework that separates them. [rag, code-migration, evaluation]

05
Evaluating Context Segmentation in Locally Deployable SLMs for Cybersecurity CTF Tasks
Small open-weight models acting as autonomous agents fall apart on long-horizon CTF challenges — tool-call output accumulates, context bloats, cognition degrades. Context segmentation splits exploitation into contextually isolated sub-problems; on picoCTF with memory-constrained gemma-4 models, the E4B variant reaches competitive rewards. The paper's framing is the sharper note — capable security agents now run locally, where API-level guardrails never apply. [agents, cybersecurity, context-management]

Scaling Clinical Judgment to Evaluate Medical AI
Blinded physician review is the gold standard for assessing clinical reasoning in LLMs, but studies rarely scale past small, single-institution panels. PrecepTron is a LoRA fine-tune of a 32-billion-parameter model on a small set of physician examples, trained to grade open-ended responses at physician level. It ships with GRAND-ROUNDS — 9,217 physician scores from 11 doctors across seven studies — as a large-scale benchmark for clinical evaluation. [evaluation, healthcare, llm-judges]

Why It Matters
▸ The alignment-eval post and K-Bench are the same finding in different clothes: a certificate earned on one surface doesn't bind the others. Last year's evals passed a model that answers cleanly — this year's agent leaks the same secret through chain-of-thought, tool calls and tool observations. If your safety or unlearning eval predates agentic deployment, it measures a system you no longer run. Rewrite against full traces; every channel the agent emits is a channel your eval can miss.
▸ Three papers converge on Dan Luu's thesis from different directions — the instruments are bent. Expert re-grading flips physics benchmark failures into passes, graph-reasoning accuracy swings on input representation alone, and CodeBLEU hands two materially different RAG pipelines the same 91%. Before trusting any leaderboard delta, or picking a base model off one via the Interconnects reading list, audit a handful of marked-wrong answers yourself. PrecepTron points at the scalable fix — train the grader, not just the model.
▸ Tan's distillation advocacy and Sacks's hands-off posture both presuppose frontier risk can be measured well enough to pace releases — a presupposition this week's evidence doesn't support. The coherent position isn't 'trust the labs' or 'don't'; it's that neither works while eval certification transfers this badly across time, context and channel. Signal's zero-knowledge sign-up is the design lesson the governance debate keeps missing: prefer architectures whose safety doesn't depend on trusting whoever holds the certificate.
