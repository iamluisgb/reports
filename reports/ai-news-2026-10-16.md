## Papers — ArXiv

### JevAgentHarness: Benchmarking, Deploying and Training Decision Models That Share Control with LLMs

Agent harnesses call a large LLM at every step, but most of those calls are just multiple-choice decisions — which tool next. This paper builds AgentDecisionBench to test delegating those decisions to cheap decision models, and finds the best isolated-question model still solved only 69.5% of full agent tasks; without a fitted confidence threshold, delegation cut success by 19.0 points. The gap between answering questions and running an agent is now measured, not assumed. **[agent harnesses, decision models, benchmarking]**

Sources: [arXiv](http://arxiv.org/abs/2610.21412v1)

### HPCAgent-Bench: A Framework for Sound Benchmarking of Code-Optimizing Agents, Harnesses, and Skills

Coding-agent benchmarks that fix one accelerator or harness cannot tell you whether a tool or skill actually pays for itself. HPCAgent-Bench specifies 689 kernels once in NumPy, derives C and Fortran references, and runs submissions through a common ABI on CPUs or GPUs — with an external judge checking correctness on hidden fuzzed inputs to close reward-hacking paths. Paired-run metrics isolate each intervention's contribution. **[code optimisation, benchmarking, hpc]**

Sources: [arXiv](http://arxiv.org/abs/2610.20673v1)

### WEAVE: Weaving Real-World Code Evolution into Dependency-Structured Tasks for Benchmarking and Training Code Agents

Repository-level benchmarks treat one issue or PR as the task, but real software work unfolds across coordinated multi-PR changes. WEAVE converts verified PR histories into executable tasks organised as bounded DAGs, and introduces Graph Credit — a deterministic, test-grounded metric for measuring contribution across dependent changes. That gives long-horizon code agents both a realistic evaluation and a usable learning signal. **[code agents, benchmarking, long-horizon tasks]**

Sources: [arXiv](https://arxiv.org/abs/2610.22039v1)

### MemScope: Evolving Agent Memory Architectures through Localized Code Repair

Self-evolving agent memory systems adapt from coarse feedback — evaluation scores, compressed summaries — which cannot localise failure, so updates end up rewriting architectures that were mostly fine. MemScope grounds evolution in evidence, using tool-use traces to pinpoint the failing component before any code change. Localised repair instead of wholesale rewrite. **[agent memory, self-evolution, failure localisation]**

Sources: [arXiv](http://arxiv.org/abs/2610.21170v1)

### Auditing Escalation Reliability in Healthcare LLM Agents: A Perturbation-Controlled Benchmark of Workflow-State Failures

An agent that answers correctly on clean inputs can still fail at the actual job: escalating when evidence is missing, stale, or conflicting. Across 400 perturbation-controlled healthcare workflow episodes, five open-weight models hit 0.97 clean accuracy yet missed 32–97% of required escalations, and the strongest 9.7B configuration dropped to 0.78 under conflict. Verbalised confidence did not close the gap. **[safety, evaluation, healthcare agents]**

Sources: [arXiv](http://arxiv.org/abs/2610.21270v1)

### SSR: Structural Signal Retriever for Scalable Agent Discovery in LLM-Orchestrated Multi-Agent Systems

As agent registries grow, dumping every Agent Card into the orchestrator's context inflates cost and latency until the window breaks. SSR is a deterministic, training-free retriever that weights lexical signals from capability-bearing card fields with IDF and scores candidates through an inverted index — keeping the candidate set compact without a learned model in the loop. **[multi-agent systems, agent discovery, retrieval]**

Sources: [arXiv](http://arxiv.org/abs/2610.21113v1)

## Why It Matters

-   The control flow around the model is where this quarter's gains live. JevAgentHarness puts a number on it — a 19.0-point success drop from naive delegation — and the scaffolding work on ARC-AGI-3 shows a single instruction change moving scores more than most model swaps would. That rhymes with Goodfire's argument that models are more legible than assumed: if the internals are legible and the harness is measurable, the differentiator is neither weights nor vibes but the code you wrap around both.

-   Benchmarks are finally learning to defend themselves. HPCAgent-Bench closes the reward-hacking paths with hidden fuzzed inputs and an external judge; WEAVE replaces the single-PR fiction with dependency DAGs; the escalation audit shows 0.97 clean accuracy coexisting with 32–97% missed escalations. The pattern across all three: headline accuracy is becoming the least informative number on the page, and perturbation, dependency, and paired-run metrics are what to ask for instead.

-   The news says the same thing from the other direction. Meta's consent-by-terms scraping and Citizen Lab's ad-tech-to-spyware chain are both stories about plumbing — supply chains and terms of service doing more damage than any model. Krea 3 betting on editing-as-primary-workload matches what WEAVE observes about real engineering: iteration across connected changes, not one-shot generation. Build for the loop, audit the pipes, distrust the clean score.
