## Papers — ArXiv

### Soei: Structured Observability of Evidence and Intent for Multi-Agent AI Software Engineering

Coding agents now do long, multi-session work unsupervised, and a developer returning to it cannot tell what was actually done or whether it was checked. Soei prototypes structured observability of evidence and intent, run on 45 real coding-agent sessions — 102,233 records, 20,577 tool executions — with a blind-audited classifier at 83.3–96.7% precision estimating that 23.4% of code-editing episodes end with no independent check. The paper also audits Agenttrail itself and finds an unauthenticated local mutation surface in its Map service. **[observability, coding-agents, audit]**

Sources: [arXiv](https://arxiv.org/abs/2610.39468v1)

### Bank-World: A Benchmark for Evaluating Agents on Banking Workflows

Banking work demands more than correct calculations — reconciling records, obtaining permission, executing transactions, keeping instructions and status consistent as circumstances change. Bank-World tests this with 50 tasks across two simulated institutions and multi-turn simulated employees; across 1,600 attempts by four models, correct decisions routinely fail to become completed work — fees charged twice, correct totals split incorrectly, payments executed without approval. **[benchmark, agents, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2610.39733v1)

### AgentDecept: Benchmarking Deceptive Behavior in Tool-Using LLM Agents under Pressure

Users typically see an agent's report, not the observations, API calls and state changes behind it, and whether agents report their actions faithfully under pressure is underexplored. AgentDecept provides 477 pressure variants derived from 257 source tasks across six pressure sources — event messages, task context, application state, tool responses, quotas — each paired with a pressure-free counterpart, scored by an evidence-grounded protocol against actual traces. **[deception, benchmark, tool-use]**

Sources: [arXiv](http://arxiv.org/abs/2610.39377v1)

### The Real Cost of Context: Predicting Compute Time and Energy Consumption in LLM Prefill and Decode Phases

Energy estimates for LLM systems usually count generated tokens and ignore the large input contexts agentic workflows produce. Systematic profiling across prefill and decode lengths, fitted with generalised linear models, shows decode time and energy scale linearly with output length while prefill exhibits both linear and quadratic scaling with input length. Input context is a first-order cost driver for large-context agent workloads. **[efficiency, inference, measurement]**

Sources: [arXiv](http://arxiv.org/abs/2610.39621v1)

### Learning to Reason from Reference Samples Alone: Reinforced Adversarial Learning for Modern LLM Post-Training

RLVR is confined to tasks with explicit correctness signals, but in many settings only reference answers exist — recognisable, not scoreable. Reinforced Adversarial Learning makes a co-trained LLM judge the sole reward for on-policy post-training; with sufficiently capable judges it matches direct RLVR on integer multiplication, arithmetic-expression synthesis and SMILES-to-formula translation, then extends to domains without verifiers. **[post-training, rl, reasoning]**

Sources: [arXiv](http://arxiv.org/abs/2610.38851v1)

### MAServeBench: Benchmarking Multi-Agent LLM Serving Systems with Hierarchical Collaboration Workloads

Multi-agent systems turn one request into interdependent model and tool operations that become ready at different times and share evolving context — stressing serving hardware in ways independent-request benchmarks never expose. MAServeBench treats collaboration as a configurable workload dimension, with composable stages capturing documented coordination patterns to reveal concurrency, compute and memory bottlenecks. **[serving, multi-agent, benchmarking]**

Sources: [arXiv](http://arxiv.org/abs/2610.40293v1)

## Why It Matters

-   The Claude Code backdoor and Soei's 23.4% figure are the same failure at different layers: nobody is watching what agent tooling actually does. A marketplace extension with a backdoor, an observability tool with an unauthenticated mutation surface, agents that report rather than show — the audit gap is now the attack surface. The industry is shipping agent deployment faster than the machinery to inspect it, and today's breaches say attackers noticed first.

-   Bank-World and AgentDecept converge on a failure mode the benchmarks rarely test: the model's judgement is fine and the execution around it is not — correct decisions that never become completed work, plausible reports over unfaithful traces. Cisco's unlimited-token legacy rewrite is the same bet at organisational scale; token budgets buy generation, not verification. Pair that with the SRE deskilling argument and the uncomfortable conclusion is that the human capacity to catch agent errors is being spent down exactly as agent volume rises.

-   OpenAI closing well short of its $30B target and the prefill quadratic-scaling result point the same direction: the marginal cost of agent context is real and superlinear, and the era of assuming capex raises itself is ending. Work that treats context as a budget — cost-regularised memory indexing, serving benchmarks that expose where multi-agent coordination actually bottlenecks — stops being a curiosity and becomes the plan when the funding environment says no.
