Papers — ArXiv
01
RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory
Frozen robot policies work better inside an agent harness, but those harnesses are hand-built and redesigned per robot or benchmark. RoboArchitect uses a coding model to watch rollouts, diagnose failures and revise the harness around the frozen policy without weight updates. On held-out scenes it lifts average success from 9.7% to 43.3% (4.5x) and on held-out tasks from 12.7% to 40.2% (3.2x), with the largest gains where the benchmark is far from the seed harness. [agent-harness, robotics, coding-agents]
arXiv
02
Real Computation or Merely Naming? A Pre-Registered Mechanism Audit of 25 Cognitive-Architecture Modules in an LLM-Based Agent System
Agent systems increasingly claim cognitive-architecture modules — global workspace, theory of mind, active inference — and treat the label as the mechanism. This pre-registered audit uses a four-question static protocol with line-number evidence and call-chain tracing on a system claiming 25 mechanisms, pre-registers falsifiable predictions for 11 modules, then replicates on the IIT-phi core of a second system with two repair experiments as positive controls. The result is a transferable test for the claim-implementation gap, not another benchmark score. [agent-audit, cognitive-architecture, verification]
arXiv
03
Dynamical Memory Transformer: Selective Recurrent Memories with Constant Cost Attention
Transformers keep an explicit token history, so KV-cache size and per-token cost grow with context. State-space models compress the past into a fixed state but lose addressability. DMT separates sequence encoding from reading: several complex-diagonal recurrent memory units with input-dependent leak rates are read by attention without going through token history. The recurrence supports an associative scan with O(T) total work and O(log T) parallel depth at fixed dimensions. [architecture, long-context, linear-attention]
arXiv
04
DAMI: Dual-Axis Memory Initialization for Enhanced Long-Context Retrieval in Gated Linear Attention
Gated linear attention has a finite-state memory whose retention is shaped by A_log, dt_bias and input activations, and controlled Gated DeltaNet runs show those parameters stay highly correlated with their initial values after training. DAMI sets geometric timescales across heads and a low-high-low input-sensitivity profile across layers before training, then calibrates the GDN-family implementation from a small activation sample without adding trainable parameters. It is evaluated across GDN, KDA, GDN2, Mamba-2 and RWKV-7 — five recurrence families — so the claim is transfer of initialization, not a single-model tuning result. [linear-attention, long-context, initialization]

Why It Matters
▸ The leverage is moving from weights to harnesses. RoboArchitect lifts a frozen policy from 9.7% to 43.3% on unseen scenes by having a coding model rewrite the control code around it, while Real Computation shows that named cognitive modules can fail a call-chain audit. The Minecraft swarm collapse is the orchestration version of the same lesson — coordination overhead, not model capability, is what breaks agent teams at scale.
▸ Verification is the bottleneck once generation gets cheap. Real Computation gives a pre-registered audit with 25 modules and 11 falsifiable predictions, which is the right shape for claims about agents — AI-generated game wikis and Apollo's zero-payoff finding are the same problem in the wild, where plausible text outruns checked value. Postgres 19's slip is the maintainer-side cost of AI-assisted discovery — more bugs found is only good if triage and review scale with it.
▸ Operational trust still fails at the boring layers. Trigger.dev exposed customer environment variables and Lenovo's fingerprint drive turned out to be an unencrypted SD card, so rotate secrets and verify hardware claims before believing the label. The JavaScript-framework inference bill and the DMT/DAMI memory work point the same way: context, memory and decode costs are now design decisions, not benchmark footnotes.
