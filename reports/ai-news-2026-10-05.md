## Papers — ArXiv CS.AI

### BitNest: Bit-Nested Speculative Decoding for Memory-Efficient LLM Inference Acceleration

Speculative decoding usually costs extra memory — a draft model or a second weight representation — which is exactly what resource-constrained devices don't have. BitNest nests a low-precision draft inside the higher-precision target's weights, building the quantised base first and recovering the target by residual refinement, so both share one physical representation. The draft and target never compete for memory, removing the usual trade-off between draft quality and storage. **[speculative-decoding, quantisation, edge-inference]**

Sources: [arXiv](http://arxiv.org/abs/2610.02800v1)

### Preserving Mathematical Reasoning in Compressed Diffusion Language Models via Trajectory-Aware Low-Rank Approximation

Compressing diffusion language models fails quietly: calibration runs on clean, fully visible activations, but inference walks through partially masked intermediate states, so the approximation is tuned for states the model never occupies. The paper formulates a trajectory-aware low-rank objective over corruption levels and masking realisations, estimated by Monte Carlo sampling of the trajectory second moment. Under matched compression budgets, trajectory-aware calibration preserves mathematical reasoning where clean-state calibration degrades it. **[compression, diffusion-lms, low-rank]**

Sources: [arXiv](http://arxiv.org/abs/2610.03326v1)

### Harness-Aware Distillation for Small Language Model Agents

When a large agent is distilled into a smaller one, the harness — context management, tools, feedback — stays in place, so standard output-imitation wastes the student's capacity relearning what the harness already provides. HAD distils only what the teacher adds beyond the harness: an action preference contrasting the teacher's choices with and without harness information, scored after the student's own reasoning, plus a validity check that discards pairs contradicting harness records. Small models get the teacher-specific competence, not the scaffolding. **[distillation, agents, small-models]**

Sources: [arXiv](http://arxiv.org/abs/2610.02858v1)

### DyadMem: A Long-Term Memory Benchmark of How Agents Work with Users

Agent memory benchmarks test what is true about a user, not how a particular agent should work with that particular user as their shared history evolves — the relationship-specific layer is left implicit. DyadMem annotates user facts and this relational memory along the same multi-session trajectories: 3,065 episodes, 50,961 sessions, 61,210 QA instances across six memory categories, with session-level capture and update gold labels rather than final-answer QA alone. **[agent-memory, benchmarks, long-term-interaction]**

Sources: [arXiv](http://arxiv.org/abs/2610.03020v1)

### ReFract: Benchmarking Perspective Awareness in Language Model Agents with Text World Models

Agents acting on physical equipment must calibrate to the user's role — what they may know, intend, and legitimately do — because mistakes there are irreversible, unlike recoverable coding errors. Existing benchmarks ignore this. ReFract provides 150 expert-validated text-world entries where the agent must infer the role's perspective and act only through tools that role may use. **[agents, safety, benchmarks]**

Sources: [arXiv](http://arxiv.org/abs/2610.03356v1)

### NeutronGym: Physics-Graded Neutron Instrument Design for LLM Agents

Testing whether agents can do physics rather than recall it requires grading that cannot be argued with. NeutronGym is an executable environment for neutron instrument design: agents build through validating tools, McStas ray-traces the result, and a level-resolved ladder scores syntax through science with no LLM judge. Seven models solve at most 7 of 16 McStasBench tasks and none meets the improvement target; RL on the reward takes Qwen3-8B from 11% to 77%. **[agents, rl-environments, scientific-instruments]**

Sources: [arXiv](http://arxiv.org/abs/2610.03631v1)

## Why It Matters

-   The local-inference stack is assembling itself piece by piece, and today's papers supply two of the missing parts. Strata's 125B on a 4090 is the headline, but BitNest's single-weight speculative decoding and trajectory-aware dLLM compression are the techniques that make such claims reproducible rather than demo-ware — they attack the same memory wall from the quantisation and decoding ends. Note the demand side too: 323 people discussing how to delete Apple Intelligence, and an on-device photo search Show HN, suggest a real constituency for models that live on their own hardware.

-   Trust is being formalised from both directions at once. Anthropic escalated a user's diary to the police while separately consulting theologians on Claude's morals — labs are deciding who they answer to, and users are not first on the list. ReFract and DyadMem are the academic shadow of the same problem: agents that must infer a user's role and maintain relationship-specific memory are agents making trust decisions continuously, and benchmarks are only now catching up to that.

-   The economics point down-market, and the governance pressure reinforces it. Harness-Aware Distillation shows the interesting part of a frontier agent is increasingly separable from the model running it — which means small local models can inherit agent behaviour without inheriting the lab that reports you. If the Anthropic story changes user behaviour at all, it will be toward exactly the local, self-hosted stack the rest of today's items describe; the papers are arriving just ahead of the demand.
