## Papers — ArXiv

### SWE-Shift: Evaluating Coding Agents in Evolving Workspaces

Repository-level coding benchmarks assume the workspace stays still while the agent works; real development does not. SWE-Shift injects task-relevant changes mid-execution across 120 scenarios and 12 change families, requiring agents to finish the task while preserving still-valid work. All 17 systems tested degrade under shifts — GPT-6 Astra falls from 67.35% to 24.79% success. **[coding-agents, benchmark, reliability]**

Sources: [arXiv](http://arxiv.org/abs/2610.32237v1)

### Compact-Bench: Measuring What Context Compaction Costs Long-Horizon Coding Agents

Context compaction lets coding agents run past their context windows, but summarisation can silently delete the state needed to finish. Compact-Bench pairs full-history and summary-only continuations from identical repository states across 146 agentic sessions and 106 production chains. Summariser choice swings stable damage from 5% to 64% of full-history successes, with Claude Opus 4.8 preserving the most repairs and DeepSeek-Flash the least. **[context-compaction, coding-agents, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2610.31710v1)

### StateMirror: Pre-Execution Detection of Hallucinated Tool Calls in Coding Agents

Coding agents routinely propose actions the environment cannot satisfy — missing packages, non-existent paths — and current frameworks only find out after execution fails. A study of 4,398 trajectories puts the recovery cost at a median 3 extra steps and 22.4K tokens per hallucination. StateMirror intercepts calls at the harness boundary, extracts state predicates via AST and command analysis, and validates them deterministically before anything runs. **[tool-use, hallucination, harness]**

Sources: [arXiv](https://arxiv.org/abs/2610.32648v1)

### Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution

Agent benchmarks grade the model and ignore the harness wrapped around it. TraceTrial-Bench decomposes harness reliability into seven components — context, execution, governance, lifecycle, observability, tools, verification — via 95 expert tasks with executable ground truth, plus a trajectory-tracing module that separates agent performance from harness failure. **[harness, evaluation, observability]**

Sources: [arXiv](http://arxiv.org/abs/2610.32285v1)

### POSEIDON: Scaling Training Environments for Scientific Agents from Code Repositories

Executable, verifiable training environments are the scarce resource in agent training, and hand-building them does not scale. POSEIDON mines scientific code repositories, decomposing workflows into four task types to extract roughly 10 times as many environments as prior pipelines from the same repository budget. The result is Pearl: 97,659 verifiable environments, with a recursive loop recovering candidates that would otherwise be discarded. **[training-environments, scientific-agents, rl]**

Sources: [arXiv](http://arxiv.org/abs/2610.32448v1)

### Not Every Agent Needs the Strongest Model

Multi-agent systems fix model assignments per role and optimise prompts alone, leaving inference cost outside the search. UniMASO jointly adapts prompts and model assignments using cost-aware Pareto search, topology-aware co-evolution and cross-level trajectory memory, across five benchmarks and five topologies. The finding in the title is the point: most roles do not need the frontier model, and the search finds which ones do. **[multi-agent, cost-optimization, prompt-optimization]**

Sources: [arXiv](http://arxiv.org/abs/2610.31743v1)

## Why It Matters

-   The price collapse — 80% cuts in months, open-weight models 'irresistibly good and cheap' on-prem, a 360M-parameter model topping the day's stories by emulating a terminal — has a paper-shaped echo in UniMASO: once you let the optimiser choose, most agent roles don't need the frontier model at all. Frontier capability is turning into a commodity input, priced like one. The interesting engineering is migrating up the stack, to what wraps the model.

-   That migration is exactly what today's arXiv haul measures. SWE-Shift, Compact-Bench, StateMirror and TraceTrial-Bench are all verdicts on the harness, not the model: compaction choice alone swings success by up to 64%, hallucinated tool calls burn 22.4K tokens each before anyone notices, and a mid-execution workspace change cuts the best agent's success rate by two-thirds. The model is increasingly the least replaceable-seeming and least differentiating part of the loop. If you are building agents, your compaction policy and state validation are your moat — and currently your biggest unmeasured risk.

-   The corollary: environments and evaluations are the new bottleneck, not parameters. POSEIDON's 97,659 mined environments and SWE-Shift's shift-injection methodology matter more than any single leaderboard score, because they generate the training and measurement signal everything else consumes. Drew Breunig's context-engineering survey and the ADRs-for-AI pattern point the same way from the practitioner side — the discipline is becoming process, versioned and reviewable, while the raw capability gets cheaper every quarter.
