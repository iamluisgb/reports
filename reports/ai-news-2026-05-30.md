## AI / LLM / Agents

### Guardrails Beat Guidance: Random rules outperform expert-curated ones for coding agents

A large-scale study (2604.11088) finds that random negative constraints improve coding agent performance as much as expert-curated rules (both +13.8pp on SWE-bench), and every individually beneficial rule is a "do not" constraint. Implications for agent configuration design.

Sources: [arXiv](https://arxiv.org/abs/2604.11088)

### How Coding Agents Fail Their Users: 20,574 real-world sessions analyzed

An observational study of developer-agent misalignment across 20K+ real coding sessions. Finds that benchmark trajectories miss how developers actually experience agent failures — the gap between benchmark success and real-world satisfaction is large.

Sources: [arXiv](https://arxiv.org/abs/2605.29442)

### Notation Matters: Are JSON and token-optimized formats better for agentic AI?

Benchmark study comparing JSON against token-optimized formats for tool invocation in LLM agents. JSON was designed for app-to-app interchange, not for LLM consumption — the study quantifies the overhead and proposes alternatives.

Sources: [arXiv](https://arxiv.org/abs/2605.29676)

### SkillTrojan: Backdoor attacks on skill-based agent systems

A novel attack vector targeting modular agent systems that compose reusable skills. SkillTrojan demonstrates how compromised skill implementations can backdoor the entire agent pipeline — a new security surface largely unexamined until now.

Sources: [arXiv](https://arxiv.org/abs/2604.06811)

## Papers — ArXiv CS.AI

### AgentDoG 1.5: A Lightweight Alignment Framework for AI Agent Safety

Addresses safety risks in open-world agents like OpenClaw. Proposes a scalable alignment framework that works with frontier LLMs that lower attack barriers. **[agents, safety, alignment]**

Sources: [arXiv](https://arxiv.org/abs/2605.29801)

### Meta-Cognitive Memory Policy Optimization for Long-Horizon LLM Agents

Improves how memory-augmented agents summarize interaction trajectories. Shows outcome-based RL is insufficient for training memory policies — proposes meta-cognitive optimization. **[agents, memory, RL]**

Sources: [arXiv](https://arxiv.org/abs/2605.30159)

### Relevance as a Vulnerability: Web Retrieval Degrades LLM Safety Alignment

External web retrieval weakens the safety alignment of LLM agents. Grounded responses come at a cost — incorporating external content bypasses alignment mechanisms that govern LLM-only outputs. **[safety, RAG, agents]**

Sources: [arXiv](https://arxiv.org/abs/2605.29224)

### How Reliable Are AI Attackers? A 400-Run Study of LLM Penetration Testing

First large-scale measurement of LLM attack consistency. Shows that LLMs can autonomously conduct multi-stage cyber attacks, but consistency varies dramatically across trials — with implications for autonomous red-teaming. **[security, pentesting]**

Sources: [arXiv](https://arxiv.org/abs/2605.30096)

### Governing Technical Debt in Agentic AI Systems

Agentic AI systems used as production infrastructure create governance challenges: multi-step reasoning, tool calling, memory, and feedback loops introduce technical debt patterns unique to agent architectures. **[SRE, governance, infrastructure]**

Sources: [arXiv](https://arxiv.org/abs/2605.29129)

### SkillTrojan: Backdoor Attacks on Skill-Based Agent Systems

Targets the modular skill-composition paradigm of modern agent frameworks. Demonstrates that compromised skill implementations create a new, largely unexamined security attack surface. **[security, agents, backdoor]**

Sources: [arXiv](https://arxiv.org/abs/2604.06811)

### Toward AI Systems That Understand Self and Others: World-Model Alignment

Multi-phase inference framework for human cognitive diversity. Addresses mutual misunderstanding not just as disagreement but as different inferential targets, state representations, and prediction errors. **[alignment, cognition]**

Sources: [arXiv](https://arxiv.org/abs/2605.29930)
