## Papers — ArXiv CS.AI

### JustFit: 200K-Token LLM Serving on a 24 GiB Laptop with Just-in-Time State Management

Open-weight models strong enough for real coding work don't fit a laptop's memory once execution state is counted. JustFit, an MLX runtime, compresses KV execution and materialises state just in time, decoupling context capacity from weight quantisation. On a 24 GiB M4 Pro running Qwen3.8-27B MXFP4 it lifts single-request context from 30,720 to 212,992 positions — 6.93× — with a 32K-input probe still at 19.11 tokens/s. **[local-inference, memory-management, apple-silicon]**

Sources: [arXiv](http://arxiv.org/abs/2609.17475v1)

### World Model Science: Self-Organized Criticality, Weak Chaos, and Metastable Belief Dynamics in Long-Horizon LLM Agents

Long-horizon agent failures look random in benchmarks; this paper reads agent trajectories through dynamical systems to show they have structure. Across 22 experiments — puzzles, tool use, embodied tasks, multi-hop retrieval — locally valid actions keep executing after global state fidelity has already failed, stress accumulation triggers abrupt collapse rather than gradual drift, and error sequences exhibit long memory. **[agents, reliability, dynamics]**

Sources: [arXiv](http://arxiv.org/abs/2609.17419v1)

### FlashVector: Agent for Hierarchical Model Serving Stack Optimization

Serving is a top cost line in production recommender systems, and optimising it traditionally needs four specialists — GPU kernels, framework computation graph, model server, on-demand feature processing. FlashVector is an agentic system that generalises the single-kernel optimisation playbook across the entire stack, chasing throughput gains that the cross-layer expertise bottleneck leaves unrealised. **[model-serving, agents, performance]**

Sources: [arXiv](http://arxiv.org/abs/2609.17391v1)

### End-to-End Latency-Minimizing and Load-Balanced Request Scheduling for Edge LLM Inference in Agentic AI Services

Agentic services want low-latency LLM inference at the edge, but heterogeneous server capabilities and evolving inference states make server selection a cross-slot coupling problem — and the latency bill for any scheduling decision only arrives after the request completes. The paper formulates an online scheduler that jointly minimises long-term average end-to-end latency and regulates load across heterogeneous edge servers, with latency models fine-grained enough to capture multi-stage LLM execution. **[edge-inference, scheduling, agentic-services]**

Sources: [arXiv](http://arxiv.org/abs/2609.17193v1)

### Do LLMs Have Values?

Alignment work keeps tripping over a duality: model values swing unpredictably under minor rewording yet resist explicit instructions to correct ingrained bias. Projecting responses from 106 LLMs — 150,000 queries each — alongside 95,000 human survey profiles into a shared sociological space, the authors find models do hold a coherent value system, but one that doesn't mirror human diversity. **[alignment, evaluation, values]**

Sources: [arXiv](http://arxiv.org/abs/2609.16589v1)

## Why It Matters

-   Strip out the launches and today is an infrastructure-fragility report — one firm inside the perimeters of OpenAI, Anthropic and Meta, a PAT takeover to admin on Baseten's production GitHub, Salesforce dark globally, Wayback still locked out. The common root is long-lived, over-scoped credentials and single chokepoints. Set against that, the local cluster — the per-watt benchmark, JustFit's 200K-token contexts on a laptop, a usable M4 GPU driver built in a month — reads less like convenience and more like hedging your dependency surface.

-   The papers chart agents moving into the last human-held layers of the stack — FlashVector tunes the full serving hierarchy rather than just kernels, and edge schedulers must commit to routing calls whose cost lands only after completion. arXiv-2609.17419 supplies the brake: locally valid actions keep firing after global state has already failed, and collapse is abrupt. Pair that with the Baseten story — standing credentials held by autonomous software are precisely the surface that got exploited — and granting an agent repo access becomes a design question with a known bad answer.

-   The loud arguments — the Dario letter, the post-Navier–Stokes bearishness — fight over capability ceilings, while the values paper reports something operational: across 106 models, values swing on trivial rewording yet resist direct correction, so prompt-level steering fails in both directions. That duality lands in shipped assistants this quarter, not in some alignment future. Meanwhile Gemini 3.8 folding Extended Thinking into the realtime Live line commits vendors to reasoning at conversational latency — the scheduling and serving papers above are the bill for that promise once it reaches the edge.
