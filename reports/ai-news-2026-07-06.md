## Papers — ArXiv CS.AI

### AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents

A framework for studying memory contracts in long-horizon agents. Questions the assumption that appending all history to every prompt is optimal — proposes bounded-memory evaluation. **[agents · memory · testbed]**

Sources: [arXiv](https://arxiv.org/abs/2607.02255)

### AgenticDataBench: Comprehensive Benchmark for Data Agents

Benchmark designed to evaluate autonomous data science agents on heterogeneous raw data processing, from exploration to insight generation. Targets the automation gap in real-world data pipelines. **[benchmark · data agents]**

Sources: [arXiv](https://arxiv.org/abs/2607.01647)

### SkillCoach: Self-Evolving Rubrics for Agentic Skill-Use

Skills are becoming the reusable operational layer for agents. SkillCoach addresses the problem of overlapping skills in realistic repositories by automatically evolving evaluation rubrics. **[agents · skills · evaluation]**

Sources: [arXiv](https://arxiv.org/abs/2607.01874)

### PACE: A Proxy for Agentic Capability Evaluation

Evaluating on benchmarks like SWE-Bench costs thousands per run. PACE proposes a lightweight proxy evaluation that correlates with full benchmark results but is orders of magnitude cheaper. **[evaluation · agents · cost]**

Sources: [arXiv](https://arxiv.org/abs/2607.02032)

### VLA-Corrector: Lightweight Detect-and-Correct for Adaptive Action Horizon

Reduces policy-call frequency in Vision-Language-Action models while preserving temporal coherence. A practical inference-time optimization for embodied agents. **[inference · VLA · optimization]**

Sources: [arXiv](https://arxiv.org/abs/2607.01804)

### Denser ≠ Better: Limits of On-Policy Self-Distillation

Challenges the prevailing view that on-policy learning in continual post-training is always beneficial. Shows that more self-distillation can degrade performance — important for model maintenance pipelines. **[training · distillation · limits]**

Sources: [arXiv](https://arxiv.org/abs/2607.01763)
