## Papers — ArXiv CS.AI

### SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning

Outcome-based RL for long-horizon agent tasks with multi-turn interaction, tool use, and environment feedback. Self-evolving on-policy distillation improves sample efficiency. **[rl, agent]**

Sources: [arXiv](https://arxiv.org/abs/2607.14777)

### SearchOS-V1: Robust Open-Domain Information-Seeking Agent Collaboration

As interaction histories grow, information-seeking agents struggle to track task progress. SearchOS-V1 proposes robust collaborative search with Tool-Integrated LLMs. **[agent, search, tool-use]**

Sources: [arXiv](https://arxiv.org/abs/2607.15257)

### Interventional Grounding Audits: Black-Box Tests for LLM Chain-of-Thought

LLMs produce CoT reasoning that appears sound but may not genuinely depend on its stated premises. Introduces step-level premise-dependency tests via predicate substitution. **[llm, reasoning, evaluation]**

Sources: [arXiv](https://arxiv.org/abs/2607.13069)

## Why It Matters

-   Agent memory and harness design are becoming first-class engineering problems. Oracle Agent Memory and the Harness Handbook signal that production agent architectures now demand the same rigor as distributed systems — state persistence, context management, failure recovery.

-   Open models are no longer playing catch-up. Kimi K3's 1422-point HN reception proves the community is ready to embrace truly open frontier intelligence when the quality gap closes. The model war is now about distribution and ecosystem, not just benchmarks.

-   The "human-in-the-loop is tired" thesis is gaining traction — as agents get more reliable, the bottleneck shifts from model capability to operational design. Every agent paper this week touches on autonomy, self-improvement, and reduced human supervision.
