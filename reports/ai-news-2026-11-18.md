## Papers — ArXiv

### Context Has a Price: Adding and Removing Context for LLM Coding Agents under Prefix Caching

Coding agents assume more context means better patches, but nobody has priced that assumption properly. Across 20,000+ runs of open models on SWE-bench Verified and Loc-Bench, retrieved code cuts read and search commands by 18–34% yet raises cost 33–42% once cached input is priced at a tenth of uncached — with no measurable resolution gain. Trimming old observations saves 19–36% without a cache discount but costs 38–116% more with one. **[coding agents, cost-accounting, prefix-caching]**

Sources: [arXiv](http://arxiv.org/abs/2611.22238v1)

### Done, But Still Working: Anytime Evaluation of When Coding Agents Should Stop

Coding agents keep working after their own tests pass, and nobody knows if the extra turns earn their cost. The authors replay ~6,000 recorded runs of eight open models in two scaffolds on SWE-bench Verified, scoring intermediate patches against hidden tests. The hindsight saving from stopping at first self-test pass ranges from under 1% to 57% depending on model and scaffold; a simple stop-after-two-identical-patches rule banks 23% in a preregistered replication. **[coding-agents, evaluation, test-verification]**

Sources: [arXiv](http://arxiv.org/abs/2611.22901v1)

### Readie: Low-Latency Code Sandboxes for AI Agents

Offloaded code execution stalls agents because no single sandbox snapshot is both compact and broad enough to pre-warm every package and dataset agent code might touch. Readie instead learns a set of small snapshots, each fast to initialise and covering a fraction of workloads, and routes execution to the right one. Set coverage beats the single fat image without paying its startup tax. **[agent-infrastructure, code-execution, snapshots]**

Sources: [arXiv](http://arxiv.org/abs/2611.22171v1)

### Multi-Agent Memory Inconsistency: Where Factual Conflicts Disappear in LLM Agents

Delegating evidence collection to worker agents with separate contexts looks like parallelism but acts as an information filter. In Harvey LAB document-review tasks across three models, delegation raises retrieval of both conflicting claims from 50.2% to 68.7% while conflict detection falls from 16.2% to 13.2% — workers report both claims for only 35.2% of retrieved pairs. More evidence reaching the lead, less contradiction surviving the trip. **[multi-agent, memory-consistency, benchmark]**

Sources: [arXiv](http://arxiv.org/abs/2611.22245v1)

### Beyond Benchmarks: Evaluating LLMs and Agentic Patterns for Static Code Analysis Warning Classification

LLMs triage false positives in static analysis well on public datasets, then underperform on unseen ones — the standard overfitting-to-benchmark failure. This study tests three models plus agentic patterns across four manually annotated real-world datasets and folds in established code-quality standards. A usable picture of where agentic triage actually holds outside the training distribution. **[code-analysis, evaluation, false-positives]**

Sources: [arXiv](http://arxiv.org/abs/2611.19086v1)

### Efficient Wide-Beam Generative Retrieval with Model-Native Trie Decoding and Shared-Context Attention

Generative retrieval predicts catalogue entries as semantic identifiers, but trie-constrained wide beams waste GPU memory on vocabulary-wide score tensors and re-attend to the same prompt per beam. Trie-Head stores the identifier trie as validated GPU tensors — no Python constraint callbacks, no retraining, scores preserved in real arithmetic — while shared-context attention reuses prompt key/value blocks across beams. A serving-path fix for document retrieval that is quietly becoming an inference bottleneck. **[generative-retrieval, inference-optimisation, gpu]**

Sources: [arXiv](http://arxiv.org/abs/2611.22309v1)

## Why It Matters

-   The day's releases — GPT-6.2's two-model drop, Microsoft's MAI Code 2 and Code 2 Flash — are still unmeasured, but the papers show what measurement looks like when it arrives. The prefix-caching study finds that a supposedly free optimisation (adding context) costs 33–42% more once cache economics are priced correctly, and that removing context flips from saving money to costing 38–116% more depending on your cache discount. Anyone budgeting agent fleets against the new flagships should treat token-count arithmetic as wrong until proven otherwise.

-   Verification is the argument practitioners are actually having — the Claude Code thread at 224 comments is about what 'done' means when the machine writes the diff — and the anytime-evaluation paper gives it numbers: up to 57% of agent spend goes to work after self-tests already pass, and even a trivial stop rule recovers 23%. Pair that with PostHog's routing-to-determinism piece and the multi-agent memory paper, where delegation raises evidence retrieval while lowering conflict detection from 16.2% to 13.2%. The pattern across all three: agent scaffolds add work and structure that quietly destroy signal, and the fix is measurement at the boundaries, not bigger models.

-   Infrastructure is consolidating around who controls the serving path: Cerebras disaggregates inference across stages, Readie attacks sandbox startup, and the ONNX Runtime repository going dark with no explanation is a reminder that the open runtimes under all of this can vanish mid-week. Gemini 4 Carbon's delay and Nvidia's Singapore disclosure change bracket the same story — the compute layer is now strategically opaque, and the papers' careful cost accounting is the only instrument most of us have for seeing through it.
