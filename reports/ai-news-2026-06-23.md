## Papers — ArXiv CS.AI

### AIR: Adaptive Interleaved Reasoning with Code in MLLMs

Following the paradigm shift initiated by OpenAI o3, interleaved reasoning with code to enhance multimodal large language models has become a pivotal research frontier. This work pushes beyond simple tool-use toward adaptive code integration during reasoning. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.23678v1)

### On the Limits of Prompt-Conditioned Language Models as General-Purpose Learners

Large Language Models are frequently portrayed as general-purpose solvers capable of arbitrary tasks. This paper argues that language is a compressed and capacity-limited interface for conveying task information, challenging the general-purpose narrative. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.23668v1)

### MAS-PromptBench: When Does Prompt Optimization Improve Multi-Agent LLM Systems?

Multi-agent systems offer a scalable path forward for agentic AI, comprising multiple LLM-based agents with system prompts governing inter-agent coordination. This benchmark evaluates when prompt optimization actually helps. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.23664v1)

### Randomized YaRN Improves Length Generalization for Long-Context Reasoning

LLMs are typically pretrained on short sequences and extended to longer ones. This work introduces Randomized YaRN, a technique that improves generalization to very long sequences beyond training distribution. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.23687v1)

### EnterpriseClawBench: Benchmarking Agents from Real Workplace Sessions

Enterprise agents increasingly operate inside workspaces, reading files, invoking tools, and delivering artifacts. This benchmark is constructed from proprietary, real-world agent sessions to measure workplace effectiveness. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.23654v1)

### Can LLMs Reliably Self-Report Adversarial Prefills?

LLMs exhibit introspective capability on benign tasks. This work extends the question to safety, examining how reliably a model recognizes that its own prior response was elicited by an adversarial prefill attack. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.23671v1)
