## Papers — ArXiv CS.AI

### RAMP: Runtime Assessing of Agentic Models in Production Systems

Production-grounded benchmark reveals catastrophic capability degradation in serial workflows — completion rates drop from 100% to 20%, none of 15 models complete the full pipeline. Computational costs differ by up to 3 orders of magnitude. **[agents, benchmark, production]**

Sources: [arXiv](https://arxiv.org/abs/2605.27492)

### Pretraining Data Exposure in LLMs: Survey of Membership Inference, Data Contamination, and Security Implications

Comprehensive survey of how LLMs leak pretraining data through membership inference attacks — a critical security concern as models scale. Covers data contamination vectors and mitigation strategies. **[security, LLM]**

Sources: [arXiv](https://arxiv.org/abs/2605.26133)

### MIRAGE: Context-Aware Prompt Injection against Mobile GUI Agents via User-Generated Content

VLMs-driven mobile GUI agents cannot reliably separate trusted UI elements from user-generated content, making them vulnerable to prompt injection attacks. Demonstrates practical attack vectors against autonomous GUI agents. **[security, agents, injection]**

Sources: [arXiv](https://arxiv.org/abs/2605.28116)

### MinT: Managed Infrastructure for Training and Serving Millions of LLMs

MindLab Toolkit (MinT) scales LoRA adapter management to 1M+ policies over shared 1T-class base models. Adapter-only handoff reduces step time by 18.3x, supports thousand-adapter active waves at cluster scale. **[infra, inference, LLM]**

Sources: [arXiv](https://arxiv.org/abs/2605.13779)

### From Detection to Recovery: Operational Analysis on LLM Pre-training with 504 GPUs

Empirical analysis of a 63-node B200 cluster (504 GPUs) over 73 days. 10/10 failure detection rate, 33.3% auto-retry success (2.7x manual), median retry interval 11 min. Identifies storage I/O bottleneck invisible at small scale. **[SRE, infra, ops]**

Sources: [arXiv](https://arxiv.org/abs/2605.09370)

### MemFail: Stress-Testing Failure Modes of LLM Memory Systems

Diagnostic benchmark isolating failure modes in summarization, storage, and retrieval operations of LLM external memory systems. Evaluates 4 state-of-the-art systems across adversarially-designed datasets. **[memory, agents, benchmark]**

Sources: [arXiv](https://arxiv.org/abs/2605.26667)

### AGORA: Inference-Free Prompt Compression for LLM Agents

Token-level compressors destroy action semantics in agent contexts. AGORA achieves >75% uncompressed performance across 8/9 cells using a structural prompt parser + 125M relevance scorer (~2ms/step), with 1.0-11.5x adaptive compression. **[agents, inference, performance]**

Sources: [arXiv](https://arxiv.org/abs/2605.26596)

### ReMoE: Boosting Expert Reuse via Router Fine-Tuning in Memory-Constrained MoE LLM Inference

Fine-tuning routers to boost expert reuse in memory-constrained MoE inference. Reduces expensive expert cache evictions from slow external storage, improving inference throughput under memory pressure. **[inference, LLM, performance]**

Sources: [arXiv](https://arxiv.org/abs/2605.27081)

### When Does Memory Help Multi-Trajectory Inference for Tool-Use LLM Agents?

Systematic study across 4 memory methods × 3 inference strategies × 4 benchmarks. Key finding: the same memory method produces different results under different inference strategies. Atomic fact extraction shortens trajectories by 19-26%. **[agents, memory, inference]**

Sources: [arXiv](https://arxiv.org/abs/2605.28224)

### HARP: Measuring Harm Amplification in Multi-Agent LLM Systems

Demonstrates that perturbations to one component in multi-agent systems propagate and amplify through the agent pipeline. A bounded risk in one agent can cause disproportionate harm downstream. **[agents, safety, systems]**

Sources: [arXiv](https://arxiv.org/abs/2605.27489)

### Defending LLM-based Multi-Agent Systems Against Cooperative Attacks

Malicious agents in multi-agent systems can inject misinformation to mislead collaborators. Proposes sentence-level rectification to detect and mitigate cooperative attacks without retraining. **[security, agents, defense]**

Sources: [arXiv](https://arxiv.org/abs/2605.28104)

### GENESIS: Harnessing AI Agents for Autonomous 6G RAN Synthesis

Agentic AI framework for 6G Radio Access Network R&D — converts intents (spec clauses, telemetry anomalies, research hypotheses) into over-the-air validated solutions. Composable agents, skills, hooks + persistent knowledge base. **[agents, networking, 6G]**

Sources: [arXiv](https://arxiv.org/abs/2605.27360)

## Why It Matters

-   The PMF breakthrough for AI coding agents means the unit economics are now real: enterprises paying $200/user/month for Claude Code and Codex isn't speculative — it's driving IPO timelines. For an SRE, this signals agents are graduating from toys to production infrastructure. The operational patterns from MinT (managing 1M+ LoRA adapters) and the 504-GPU failure analysis paper are the kind of infra knowledge that becomes table stakes in 12 months.

-   The ITBench-AA result — frontier models scoring below 50% on enterprise IT tasks — is the honest baseline the field needs. Combined with RAMP's finding that task completion collapses from 100% to 20% in serial workflows, the message is clear: agents are powerful but not yet reliable for production IT operations without oversight. The observability and scheduling papers (DynaSchedBench, MemFail) directly address the failure modes hitting agent systems in the wild.

-   Iran's partial internet restoration tracked by Cloudflare Radar and the push notification platform politics between Apple/Google both reinforce a theme: the infrastructure layer is increasingly where geopolitical and platform power plays manifest. For an SRE running infrastructure at any scale, understanding these dynamics is as important as knowing your Kubernetes version.
