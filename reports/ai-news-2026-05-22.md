## Papers — ArXiv CS.AI

### Agent JIT Compilation for Latency-Optimizing Web Agent Planning and Scheduling

Computer-use agents automate tasks by generating sequences of tool calls. Current implementations follow a sequential fetch-screenshot-execute loop where each iteration requires an LLM call, resulting in high latency. This paper introduces JIT compilation for web agent planning. **[agent, inference]**

Sources: [arXiv](https://arxiv.org/abs/2605.21470)

### PALS: Power-Aware LLM Serving for Mixture-of-Experts Models

LLM inference drives significant GPU energy consumption. While prior systems optimize throughput and latency, they treat GPU power as a static constraint rather than a controllable resource. PALS introduces power-aware serving for MoE models. **[llm, inference, model]**

Sources: [arXiv](https://arxiv.org/abs/2605.21427)

### Frontier: Towards Comprehensive and Accurate LLM Inference Simulation

Modern LLM serving combines disaggregated execution, complex parallelism, and stateful workloads. Existing simulators lack the architectural completeness to explore this design space. Frontier provides comprehensive LLM inference simulation. **[llm, inference]**

Sources: [arXiv](https://arxiv.org/abs/2605.21312)

### OCTOPUS: Optimized KV Cache for Transformers via Octahedral Parametrization

The KV cache dominates memory bandwidth in long-context autoregressive inference. OCTOPUS uses rotation-preconditioned codecs with octahedral parametrization for near-optimal KV compression. **[transformer, inference, quantization]**

Sources: [arXiv](https://arxiv.org/abs/2605.21226)

### APEX: Autonomous Policy Exploration for Self-Evolving LLM Agents

LLM agents cannot learn on the fly at test time. APEX enables self-evolving agents that accumulate memory and reflection across episodes without requiring model-weight updates. **[agent, llm, autonomous]**

Sources: [arXiv](https://arxiv.org/abs/2605.21240)

### SpecBench: Measuring Reward Hacking in Long-Horizon Coding Agents

As long-horizon coding agents produce more code than any developer can review, oversight collapses onto test suites. Reward hacking naturally arises. SpecBench decomposes software engineering to measure this phenomenon. **[agent, benchmark, coding]**

Sources: [arXiv](https://arxiv.org/abs/2605.21384)

### Insights Generator: Systematic Corpus-Level Trace Diagnostics for LLM Agents

Diagnosing LLM agent failures remains manual and doesn't scale. This work formalizes systematic trace diagnostics that can analyze production-scale agent execution corpora. **[agent, llm, system]**

Sources: [arXiv](https://arxiv.org/abs/2605.21347)

### Beyond Text-to-SQL: An Agentic LLM System for Governed Enterprise Analytics

Non-technical users still face barriers with BI tools. An agentic LLM system provides governed enterprise analytics with natural language access to structured data and API integration. **[agent, llm, system]**

Sources: [arXiv](https://arxiv.org/abs/2605.21027)

### Terminal-World: Scaling Terminal-Agent Environments via Agent Skills

Terminal agents are bottlenecked by scarce high-quality training data. Terminal-World scales terminal-agent environments by bootstrapping from partial sources and using agent skills. **[agent, scaling]**

Sources: [arXiv](https://arxiv.org/abs/2605.20876)

### Causal Past Logic for Runtime Verification of Distributed LLM Agent Workflows

Distributed LLM agent workflows should not be monitored as sequential logs. Causal past logic extends ZipperGen with runtime verification respecting causal visibility in asynchronous execution. **[agent, llm, security]**

Sources: [arXiv](https://arxiv.org/abs/2605.20923)

### GraphRAG on Consumer Hardware: Benchmarking Local LLMs for Healthcare EHR Schema Retrieval

GraphRAG extends RAG to structured reasoning over complex corpora, but reliability under resource-constrained deployments is unclear. This benchmarks local LLMs for healthcare EHR retrieval. **[llm, retrieval, benchmark]**

Sources: [arXiv](https://arxiv.org/abs/2605.20815)

### Quality and Security Signals in AI-Generated Python Refactoring Pull Requests

AI agents increasingly contribute to code refactoring. This paper provides empirical evidence on quality and risk characteristics of agent-authored refactoring edits in real-world projects. **[security, code]**

Sources: [arXiv](https://arxiv.org/abs/2605.21453)

### Multi-Stream LLMs: Parallelizing Prompts, Thinking, and I/O

Even advanced AI agents function on message exchange formats. Multi-Stream LLMs introduce parallelizing prompts, thinking, and I/O into separate processing streams. **[llm, inference]**

Sources: [arXiv](https://arxiv.org/abs/2605.12460)

### CODA: Rewriting Transformer Blocks as GEMM-Epilogue Programs

Transformer training spends nontrivial time on memory-bound operators. CODA rewrites normalization, activations, and residual updates as GEMM-epilogue programs for better compute utilization. **[transformer, inference]**
