## Headlines

### OpenAI announces GPT-5.6 Sol, Terra & Luna — public launch Thursday

Three-model family: **Sol** (flagship LLM), **Terra** (grounded reasoning & coding), and **Luna** (creative/generation). Marks a strategic shift from one-model-fits-all to specialized model variants by modality. First time OpenAI launches multiple aligned models as a named family.

Sources: [OpenAI (X)](https://twitter.com/OpenAI/status/2074704958419792299) [HN](https://news.ycombinator.com/item?id=48827402)

### Claude Fable 5 extended to all paid plans through July 12

Anthropic extends access to Fable 5, its multimedia generation model, across all paid plans for an additional week. Signals confidence in the model's capabilities and ongoing expansion of the Claude ecosystem beyond text.

Sources: [Anthropic (X)](https://twitter.com/claudeai/status/2074548242386178258)

### StateFuse: Deterministic Conflict-Preserving Memory for Multi-Agent Systems

Novel memory architecture that preserves conflicting observations across agent branches, retries, and replicas instead of collapsing them behind opaque overwrite rules. Directly addresses the state-collapse problem in LangGraph and similar multi-agent orchestration frameworks.

Sources: [arXiv](https://arxiv.org/abs/2607.05844)

### AI Meets Cryptography: Model finds bugs in Cloudflare's Circl library

An AI-driven security analysis of Cloudflare's Circl (elliptic curve crypto library) discovered previously unknown implementation vulnerabilities. Published by zkSecurity — implications for AI-assisted security auditing of critical infrastructure.

Sources: [zkSecurity](https://blog.zksecurity.xyz/posts/circl-bugs/) [HN](https://news.ycombinator.com/item?id=48821749)

## AI / LLM / Agents

### Beyond the Leaderboard: A Synthesis of Tool-Use, Planning, and Reasoning Failures in LLM Agents

Taxonomy of recurring failure modes that standard benchmarks obscure — tool over-invocation, planning horizon collapse, coordination failures in multi-agent settings. Essential reading for anyone building agentic systems in production.

Sources: [arXiv](https://arxiv.org/abs/2607.05775)

### Memory in the Loop: In-Process Retrieval as Extended Working Memory for Language Agents

Proposes moving memory inside the agent loop — read and written on every observe-reason-act step — rather than queried once per turn. The obstacle has always been latency; this work shows it's feasible with optimised retrieval architecture. Directly relevant to LangGraph persistent state design.

Sources: [arXiv](https://arxiv.org/abs/2607.05690)

### Controlling Tool Use with Heading-Specific Activation Steering

Investigates whether tool-use decisions have stable internal representations in LLMs that can be steered. Shows heading-specific activation patterns that predict and control unnecessary tool invocation — reduces tool calls without sacrificing accuracy.

Sources: [arXiv](https://arxiv.org/abs/2607.05790)

### FirstResearch: Auditable Question Formation for LLM Scientific Discovery Agents

LLMs for scientific discovery often propose plausible-sounding research questions without exposing their reasoning. FirstResearch provides an auditable pipeline for question formation, making the scientific discovery process transparent and reproducible.

Sources: [arXiv](https://arxiv.org/abs/2607.05682)

## Why It Matters

-   GPT-5.6 Sol/Terra/Luna marca un giro estratégico en OpenAI: modelos especializados por modalidad en vez de un modelo único todoterreno. Para quien construye agentes, esto significa elegir el modelo correcto para cada etapa del pipeline — no uno para todo.

-   La memoria determinista para sistemas multi-agente (StateFuse, Memory in the Loop) resuelve el cuello de botella práctico de agentes LangGraph en producción: cómo mantener estado coherente cuando múltiples agentes colaboran, ramifican y reintentan sin colapsar información conflictiva.

-   El hallazgo de vulnerabilidades criptográficas mediante AI (Cloudflare Circl) confirma que la auditoría de seguridad asistida por modelos ya no es teórica — es un vector productivo que debería integrarse en pipelines de seguridad SRE.
