## Papers — ArXiv CS.AI

### Empirical Evaluation of Task-Based Permission Scoping Architecture for AI Agents

AI agents inherit employee-shaped credentials: one static permission set fixed at deployment, covering everything the role might ever need, exposed whether or not the current task uses it. This paper evaluates end to end a three-source architecture of role-based permission ceilings, a per-task permission classifier and policy-based prohibitions, measured against a released 600-prompt labelled dataset for task-context mismatch. The goal is preemptive elimination of exposure rather than detection after a compromised or misaligned agent acts. **[agents, security, access-control]**

Sources: [arXiv](http://arxiv.org/abs/2609.15422v1)

### Semantic-TVM: Structure-Preserving Trustworthy Virtual Memory for Memory-Augmented and Tool-Using Agents

Memory-augmented and tool-using agents hand exact private values to remote LLMs whenever retrieved memories, tool actions or observations leave the machine; one-way masking protects them but breaks trusted execution and leaks anyway through later observations. Trustworthy Virtual Memory keeps exact values local behind a protected view — Rule-TVM swaps whole fields for recoverable handles, Semantic-TVM masks only the sensitive spans a trusted local model predicts. Span-level projection recovers most of the utility whole-field replacement destroys: 84.17% versus 52.33% task success on DeepSeek over Memory-EHR, with measured exposure held low on both Memory-EHR and Memory-RAP across two providers. **[agents, privacy, memory]**

Sources: [arXiv](http://arxiv.org/abs/2609.15011v1)

### MemRiskBench: Trace-Aware Risk-Preserving Evaluation for Long-Horizon LLM Agents

Long-horizon agents accumulate memory across sessions, and the failures that matter — stale facts, cross-user leakage, revoked-memory reuse — are sparse enough to vanish into aggregate scores: a model at 78% average accuracy can still leak data in 4% of episodes. MemRiskBench fixes the measurement with a five-category risk taxonomy checked by deterministic, trace-grounded rules — no LLM-as-judge on the pass/fail path — over a 120-episode scripted benchmark run against five quantised instruction-tuned models. A risk-preserving subset selector keeps those rare high-severity episodes alive under benchmark compression. **[agents, evaluation, safety]**

Sources: [arXiv](http://arxiv.org/abs/2609.14976v1)

### MAPS: Memory-Aware Predictive Scheduling Framework for Large Language Model Serving

Disaggregated LLM serving has a structural flaw: output lengths are unknown at admission, so memory-bound decode instances land unevenly and load imbalance persists under bursty, personal-device workloads. MAPS predicts output length with device-assisted speculation overlapped with cloud-side prefilling at negligible latency cost, then applies uncertainty-aware calibration to derive output-length upper bounds with target coverage. A hierarchical global-local scheduler builds on those bounds to cut inter-decode imbalance safely despite generation randomness. **[serving, scheduling, inference]**

Sources: [arXiv](http://arxiv.org/abs/2609.15359v1)

### Empirical Evaluation of Open-Source Large Language Models for Retrieval-Augmented Generation in ESG Domain

Teams lack solid evidence on which open-source models survive domain-specific RAG, and ESG KPI extraction is a demanding test: real documents, compliance-grade answers, no tolerance for faithfulness gaps. This evaluation runs seven open models from 2B to 30B parameters over 498 real-world ESG reports from EU-listed companies (2010–2024), with 100 persona-based QA pairs scored on RAGAS metrics including contextual recall, precision and faithfulness. A usable baseline for anyone choosing a small open model for document-grounded extraction. **[rag, evaluation, open-source]**

Sources: [arXiv](http://arxiv.org/abs/2609.15242v1)

## Why It Matters

-   The through-line today is agents crossing from tools to principals: OpenAI's crawler knew the RubyGems vulnerability before the maintainers, Pion proposes an agent running a company, and Perplexity's right to browse and buy on a user's behalf is now a federal appeals court question. The papers supply the control plane that autonomy currently lacks — task-scoped permissions evaluated end to end on 600 prompts, virtual memory that keeps private values local without gutting utility, and memory-risk evals built for tail events. These briefings used to lead with capability results; the load is shifting to authorisation and audit, and that inversion is the actual signal.

-   Aggregate numbers are structurally blind to the failures that matter. MemRiskBench makes the point formally — 78% mean accuracy coexisting with a 4% cross-user leak rate — and Patch Tuesday makes it operationally, with a routine fleet update breaking audio, clipboard paste and remote access in one KB sweep. The discipline is identical whether the failure is a model, a patch or a supply chain: score the tail, stage the rollout, keep full traces.

-   Trust boundaries are moving below the model. Apple shipping Siri with a swappable Claude/ChatGPT backend and Ubuntu completing the Rust coreutils swap both treat the underlying engine as a replaceable component — which is precisely why safety guarantees can no longer be model properties. If the backend changes on a config flag, permission scopes and memory protections must live in the runtime beneath it; expect the Ninth Circuit and package registries like F-Droid to draw those lines before benchmarks do.
