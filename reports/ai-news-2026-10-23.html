Papers — ArXiv
01
Stale Instruction Files Override the Code in Coding Agents: A One-Sentence Fix
Coding agents follow a project's instruction file even when it contradicts the existing code — and even when they notice the contradiction. Across 320 runs on 40 Python projects with deliberately conflicting conventions, 90.1% of agent choices followed the stale file; Claude Code flagged the conflict in 79 of 80 runs and then obeyed it anyway, and Codex CLI rewrote conforming code to match the file in 20 of 80 runs. A single sentence in the user-level instruction file giving the code precedence largely fixes it. [coding-agents, evaluation, prompt-engineering]
arXiv
02
Certified Execution Harness for Agentic AI: Safe and Least-Intrusive Petri-Net Supervisory Control Between Reasoning and Action
Prompt injection defeats wording-based defences, so this paper formalises the harness between an LLM and its tools as a Petri-net supervisory control problem: capabilities, approvals and budgets are tokens, and a transition fires only if its marks are present. An injected request whose preconditions are unmet or already spent is refused regardless of phrasing, with safety guarantees that transfer to the running system under four stated assumptions. A replanning closed loop, where each retry costs an inference call, shows the conventional supervisor can be arbitrarily more intrusive than needed — the paper derives a least-intrusive alternative. [agent-safety, formal-methods, tool-use]
arXiv
03
EpiSEM-Bench: Evaluating Safety and Evidence Recovery in LLM Agents under Missing Evidence
A tool response that silently omits a safety-relevant fact can push an agent into a prohibited action even when every statement it received was true and the user's request was benign. EpiSEM-Bench provides 300 matched unsafe/safe task pairs across six domains and measures unsafe execution by systematically suppressing critical evidence, including the minimum observed failure cardinality. An independent audit checks whether agents actively seek the missing facts and withhold the prohibited action while still completing permitted work. [agent-safety, benchmarks, tool-use]
arXiv
04
Harnessing Language Models as Optimization Modeling Agents
Translating natural-language optimisation problems into correct solver programs is unreliable, and prior fixes leaned on agentic workflows or task-specific post-training. OPTICYCLE and OPTISTATE are two lightweight inference harnesses using a single model role and no extra training, evaluated on nine benchmarks totalling 2,634 problems across 11 Qwen variants from 0.6B to 27B parameters. Execution-guided revision improves macro accuracy over direct generation for every model tested, by up to 49.46 percentage points, and both harnesses beat six adapted baselines. [inference-harnesses, optimization, evaluation]

05
Multi-agent LLMs on the Cloud-Edge-IoT Continuum: A Systematic Mapping Study on Architectures, Deployment, and Evaluation
Multi-agent LLM systems deployed across devices, edge nodes and cloud services face latency, privacy and bandwidth constraints that single-pipeline deployments do not, and the design space had not been mapped. From 831 records the authors selected 45 primary studies and classified architecture family, deployment pattern, domain and evaluation practice. Five architecture families recur, and the survey records how rarely systems are evaluated rigorously or released with public code or data. [multi-agent-systems, survey, deployment]

Why It Matters
▸ The day's through-line is containment, and it arrives from three directions at once: NVIDIA ships OpenShell as an OS-level sandbox, the Petri-net harness paper certifies refusal at the tool boundary, and EpiSEM-Bench shows the threat is subtler than injection — agents execute prohibited actions on true statements when the disqualifying fact was simply never returned. Sandboxing the filesystem does not solve the second problem; an agent can be fully contained and still act wrongly on partial evidence. Benchmarks that suppress facts rather than corrupt them are the right instrument, and the failure-cardinality framing gives you a number to track across model upgrades.
▸ The stale-instruction-file result is the sharpest finding here and cheap to act on: agents follow written instructions over observed code 90% of the time even while explicitly noticing the conflict. That is Dijkstra's 1978 argument playing out in reverse — natural language is now the authoritative artefact and the code defers to it, which is exactly the hierarchy he warned about. The one-sentence fix (state that existing code takes precedence) belongs in every AGENTS.md and CLAUDE.md today; the deeper lesson is that instruction files are a trust boundary, and nobody is version-controlling them with the same care as the code they override.
▸ The harness papers converge on an uncomfortable economics: OPTICYCLE and OPTISTATE get up to 49 points of accuracy from execution-guided revision with zero additional training, and the Petri-net supervisor buys formal safety guarantees without touching the weights. Capability and safety are both migrating out of the model and into the scaffolding around it — which means harness quality, not model choice, is increasingly where engineering effort pays off, and also where your failure modes live. The cloud-edge mapping study's finding that most multi-agent deployments ship without public code or rigorous evaluation suggests that layer is being built faster than it is being audited.
