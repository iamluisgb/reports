## Papers — ArXiv CS.AI

### DecisionBench: Benchmark for Emergent Delegation in Long-Horizon Agentic Workflows

A benchmark substrate for emergent delegation in long-horizon agentic workflows. Fixes task suites, peer-model pools, and delegation interfaces to evaluate routing fidelity and delegation ceilings. Reference sweep across 23,375 task instances reveals large unrealized headroom.

Sources: [arXiv:2605.19099](https://arxiv.org/abs/2605.19099)

### Library Drift: Diagnosing and Fixing Silent Failure Mode in Self-Evolving LLM Skill Libraries

Unbounded skill accumulation without lifecycle management causes retrieval degradation and false-positive injections in self-evolving LLM agents. Proposes outcome-driven pruning strategies.

Sources: [arXiv:2605.19576](https://arxiv.org/abs/2605.19576)

### Towards Multi-Model LLM Schedulers: Empirical Insights into Offloading and Preemption

Empirical study of serving multiple LLM architectures on shared heterogeneous hardware. Covers resource allocation, dispatching, and scheduling trade-offs in multi-model deployments.

Sources: [arXiv:2605.19593](https://arxiv.org/abs/2605.19593)

### Conflict-Resilient Multi-Agent Reasoning via Signed Graph Modeling

Addresses naive aggregation in LLM-based multi-agent systems. Introduces signed graph modeling to handle adversarial agent interactions rather than assuming uniform cooperation.

Sources: [arXiv:2605.19418](https://arxiv.org/abs/2605.19418)

### Attention-Guided Reward for RL-based Jailbreak against Large Reasoning Models

Explores safety risks of exposing LRM internal reasoning. Uses attention-guided rewards in RL to jailbreak large reasoning models, highlighting new attack surfaces.

Sources: [arXiv:2605.19485](https://arxiv.org/abs/2605.19485)

### POLAR-Bench: Diagnostic Benchmark for Privacy-Utility Trade-offs in LLM Agents

Evaluates how well LLM agents follow user-defined privacy constraints when interacting with adversarial third-party systems. Tests robustness of intent preservation.

Sources: [arXiv:2605.19127](https://arxiv.org/abs/2605.19127)

### Formal Skill: Programmable Runtime Skills for Efficient and Accurate LLM Agents

Moves beyond informal Markdown skills to programmable runtime skills. Introduces formal specifications that make agent tool use more reliable and verifiable.

Sources: [arXiv:2605.19604](https://arxiv.org/abs/2605.19604)

### Generative Recursive Reasoning

Explores Recursive Reasoning Models (RRMs) as an alternative to autoregressive sequence extension. Iterative latent-state refinement with shared transition functions for extended computation.

Sources: [arXiv:2605.19376](https://arxiv.org/abs/2605.19376)

## Why It Matters

-   Karpathy at Anthropic is the biggest AI talent move of 2026 so far. His expertise in building accessible AI systems (TinyLLM, GPT-4V analysis) directly complements Anthropic's constitutional AI approach — expect a major push on AI safety tooling and education.

-   SynthID going mainstream (Google → OpenAI adoption) signals the industry's pivot from "AI content detection is optional" to "provenance is a baseline requirement." The Remove-AI-Watermarks tool on HN shows the pushback is already forming.

-   GitHub being compromised is a supply-chain wake-up call. With AI code generation becoming ubiquitous, the trust surface for dev infrastructure has never been larger. The SRE community needs to treat code hosting platforms as critical path infrastructure.
