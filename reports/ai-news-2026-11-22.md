## Papers — ArXiv

### Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)

News reports of LLM agent failures — Replit's coding agent deleting a production database — say what broke but rarely validate the cause their own narrative blames. ROGUE-AI rebuilds each reported incident offline alongside a matched control that differs only in the blamed cause, then runs agents on both. It reproduces the reported harm in 89% of 108 attempted replications. **[agentic security, incident replication, root-cause audit]**

Sources: [arXiv](https://arxiv.org/abs/2611.26553v1)

## Why It Matters

-   The day split cleanly in two: 2,402 points for a hurried GRH claim against 939 for a machine-checked Riemann proof, and the announcement won the traffic. ROGUE-AI imports the same corrective into agent engineering — don't read the incident report, rebuild it offline with a matched control and check whether removing the blamed cause removes the harm. That 89% replication rate is the first serious evidence that agent-incident reports are mostly reproducible rather than folklore.

-   The production side has no such discipline. Together.ai's disclosure of leaked June–July prompts, OpenRouter's incident catalogue for upstream providers, and the FBI database compromise all describe the same gap: data flowing through hosted infrastructure with no verification layer comparable to what Lean does for proofs or ROGUE-AI does for failures. Read the OpenRouter log before routing anything proprietary — the incidents are now enumerated, which means they are priceable.

-   The engineering frontier is meanwhile moving toward constraint — LLMs editing machine code from raw hex, an agent targeting DOS, Inkling-2-Mini in 5.4 GB. The pattern worth tracking: capability under limits is advancing faster than accountability under scale. If ROGUE-AI's harness becomes standard practice, incident post-mortems for agents stop being press releases and start being experiments; until then, assume every agent failure report you read is 89% likely to be true and 100% unverified.
