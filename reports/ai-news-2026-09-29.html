Papers — ArXiv CS.AI
01
UserProxyBench: Evaluating LLM User Simulators for Agent Benchmarks and Training
Interactive agent benchmarks and multi-turn RL put a second LLM in the user's seat, yet score only the agent — nobody checks whether the simulated user plays its assigned role. UserProxyBench adds an evaluation layer over the tau-bench family with a User Fidelity Score for adherence to private user instructions. Holding the agent fixed at GPT-5.5 and swapping only the user proxy across 375 enterprise tasks moves mean reward by 15.2 points, and 24.4% of successful episodes contain a user-specification violation — the dominant failure being premature disclosure. agents, evaluation, benchmarks

02
Thinking Before Thinking: Scaling Agentic Inference Through Meta-Reasoning
Long agent runs turn execution control — which partial work to build on, when to restart, when to stop — into a task of its own. This harness splits the job: workers do the task-level computation while a controller consolidates what the run has established, prices each next option against the remaining budget, and dispatches with context drawn from persistent memory. Between decisions the controller carries a compact account of the run instead of replaying full history, with baselines spanning production coding agents at matched compute. agents, inference, orchestration

03
Do LLM Agents Execute the Plans They Declare?
Planner–executor agents can fail by picking the wrong plan or by executing the right one badly, and final task success cannot distinguish the two. The authors have the LLM declare one of four planning modes — Predefined, Sequential, Hierarchical, Search — and route each task to a pattern-specific executor. Across four benchmarks and three LLMs, generic Plan+ReAct frequently fails to preserve the planning structure it declared, with the gap widening on longer plans. agents, planning, reliability
arXiv
04
FOCUS: Training-Free Decision-Preserving Context Compression for LLM Agents
Agent histories grow linearly with task length, so inference cost scales quadratically while attention dilutes — and existing compressors learn what to discard offline, fixing a policy before the test-time trajectory exists. FOCUS reframes compression as causal decision preservation: keep the past interactions that actually shape future decisions, computed entirely at test time with no offline data or fine-tuning. agents, context, efficiency

05
Probability is Not Enough: Exploring and Counting Divergent Tokens for Reasoning Uncertainty Quantification in LLMs
Confidence scores for chain-of-thought answers lean on the probabilities of selected key tokens, and a pilot study here shows even coarse substitutes for those probabilities improve calibration — so the signal is not what it appears to be. The proposed Divergent Token Confidence counts the decoding steps at which two models strongly disagree, located via Jensen–Shannon divergence between next-token distributions along the same reasoning trajectory. uncertainty, calibration, reasoning

Why It Matters
▸ OpenAI's day — near-Astra intelligence at a fifth of Astra's price, plus always-on Dots — treats agent reliability as a distribution problem already solved. The papers treat it as a measurement problem barely started: swap only the simulated user behind a fixed GPT-5.5 agent and mean reward moves 15.2 points, a quarter of successful episodes break the user spec, and declared plans routinely fail to survive execution on longer horizons. Read those numbers as the error bars on the Dots pitch.
▸ Persistence changes the economics of control rather than of intelligence. Always-on agents accumulate history, and history is where cost and failure compound — FOCUS keeps only the interactions that causally shape future decisions, and the meta-reasoning harness makes budget-aware dispatch explicit because long runs turn when to stop into the binding constraint. Cheap tokens make long runs affordable, which also makes sloppy harnesses expensive. In the always-on regime the scarce resource is execution control, not model quality.
▸ Verification is becoming the political story as fast as the technical one. Livenerf exists because providers change model behaviour without versioning it — the same trust gap DTC attacks by measuring where two models diverge mid-trajectory rather than trusting token probabilities. Add 500,000 station scans yielding zero arrests and one false positive, DraftKings optimising against chronic gamblers, and Anthropic's warning that GLM-5.3 spreads offensive cyber capability beyond well-resourced labs: capability is being deployed ahead of both evidence and controls. Newport's call to investigate the labs gains force less from its argument than from the industry's habit of supplying its own exhibits.
