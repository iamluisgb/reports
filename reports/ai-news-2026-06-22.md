## AI / LLM / Agents

### LedgerAgent: Structured State for Policy-Adherent Agents

Novel agent architecture that maintains structured task state across turns while enforcing policy constraints for safe tool-calling in customer-service domains. The ledger pattern is a practical design for production agent systems.

Sources: [arXiv](https://arxiv.org/abs/2606.20529v1)

### Probe-and-Refine Tuning of Repository Guidance for Coding Agents

Improves LLM-based coding agents by tuning them to understand repo-level structure — which files house which subsystems — leading to better code generation without needing to reprocess the entire codebase each turn.

Sources: [arXiv](https://arxiv.org/abs/2606.20512v1)

### UltraQuant: 4-bit KV Caching for Context-Heavy Agents

Context-heavy agents place extreme pressure on KV caches due to long prefix reuse. UltraQuant quantizes KV cache entries to 4-bit, achieving dramatic memory reduction with minimal accuracy loss — directly applicable to agent serving infrastructure.

Sources: [arXiv](https://arxiv.org/abs/2606.20474v1)

### LLM Alignment Using Implicit User Feedback

Novel alignment approach using implicit user signals (mouse movements, eye tracking) instead of explicit preference labels. Could reduce the cost and bias of RLHF data collection pipelines.

Sources: [arXiv](https://arxiv.org/abs/2606.20482v1)

## Papers — ArXiv CS.AI

### LedgerAgent: Structured State for Policy-Adherent Tool-Calling Agents

Policy-adherent tool-calling agents in customer-service domains must maintain task states across turns while calling tools safely. The LedgerAgent architecture introduces a structured state ledger that tracks compliance boundaries explicitly. **[Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20529v1)

### Sovereign Execution Brokers: Certificate-Bound Authority in Agentic Control Planes

Autonomous agents are increasingly connected to cloud, deployment, and data-control workflows, but production mutation authority remains an unsolved security problem. This paper introduces certificate-bound execution brokers for fine-grained agent permissions. **[Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20520v1)

### Probe-and-Refine Tuning of Repository Guidance for Coding Agents

LLM-based coding agents need higher-level operational knowledge about a repository — which files house which subsystems, how modules connect — to generate coherent code. This work proposes a probe-and-refine tuning approach. **[Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20512v1)

### Efficient and Sound Probabilistic Verification for AI Agents

Securing AI agents that operate in complex digital environments has become a critical need. This paper presents a runtime monitoring approach that provides probabilistic guarantees about agent behaviour. **[Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20510v1)

### Contagion Networks: Evaluator Bias Propagation in Multi-Agent LLM Systems

When large language models serve as evaluators in multi-agent systems, their systematic evaluation biases propagate through the network. This paper models and measures bias contagion in multi-agent evaluation pipelines. **[Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20493v1)

### What Do Safety-Aligned LLMs Learn From Mixed Compliance Demonstrations?

Prior work has shown that in-context demonstrations can jailbreak language models, but it remains unclear how models internalise mixed compliance signals. This paper analyses the mechanism behind demonstration-based jailbreaks. **[Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20508v1)

### UltraQuant: 4-bit KV Caching for Context-Heavy Agents

Context-heavy agents place unusual pressure on the key-value (KV) cache: long prefixes are reused across many short turns. UltraQuant applies 4-bit quantization to KV entries, dramatically reducing memory footprint. **[Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20474v1)

### Multi-LCB: Extending LiveCodeBench to Multiple Programming Languages

LiveCodeBench is extended to multiple programming languages, providing a more comprehensive evaluation benchmark for code-generating LLMs and coding agents across Python, JavaScript, Java, C++, and Rust. **[Jun 2026]**
