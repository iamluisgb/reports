## Papers — ArXiv CS.AI

### EvoTrainer: Co-Evolving LLM Policies and Training Harnesses for Autonomous Agentic Reinforcement Learning

Proposes co-evolution of training harness with LLM policy in agentic RL — shifting bottlenecks and scalar rewards mask diverse failure modes, so the harness adapts as the policy learns. **[agent, rl]**

Sources: [arXiv](https://arxiv.org/abs/2606.03108)

### The Ringelmann Effect in Multi-Agent LLM Systems: A Scaling Law for Effective Team Size

Derives a two-parameter scaling law showing diminishing returns as agent team size grows — effective team size saturates. Named after the Ringelmann effect from social psychology: coordination overhead eats individual contribution. **[agent, scaling]**

Sources: [arXiv](https://arxiv.org/abs/2606.02646)

### Agentic Chain-of-Thought Steering for Efficient and Controllable LLM Reasoning

Existing efficient reasoning methods control thinking length by shearing the reasoning chain at inference time. This work introduces agentic steering that dynamically allocates token budgets per reasoning step for controllable efficiency. **[llm, reasoning]**

Sources: [arXiv](https://arxiv.org/abs/2606.03965)

### Benchmarking Security Risk Detection and Verification in Open Agentic Skill Ecosystems

Open agent platforms let community contributors publish skills that agents invoke at runtime. This creates supply-chain risk — malicious contributors can hide harmful behavior inside seemingly benign skills. Benchmark for detecting and verifying such risks. **[agent, security]**

Sources: [arXiv](https://arxiv.org/abs/2606.00925)

### Diagnosing Knowledge Gaps in LLM Tool Use: An Agentic Benchmark for Novel API Acquisition

LLMs for code generation often need APIs absent from pretraining data — models must coordinate signatures, module paths, and semantics they've never seen. Benchmark quantifies this novel-API gap and proposes acquisition strategies. **[llm, tools]**

Sources: [arXiv](https://arxiv.org/abs/2606.03657)

### Scaling Behavior of Single LLM-Driven Multi-Agent Systems

Fundamental study of scaling dynamics in LLM-based multi-agent systems — how agent count, diversity, and interaction topology affect task completion. Finds diminishing returns past a critical agent count. **[agent, scaling]**

Sources: [arXiv](https://arxiv.org/abs/2606.00655)

### MCP-Persona: Benchmarking LLM Agents on Real-World Personal Applications via Environment Simulation

Simulates real-world personal application environments to benchmark LLM agents on tasks like scheduling, email management, and workflow automation. Tests how well agents generalize across apps and user contexts. **[agent, benchmark]**

Sources: [arXiv](https://arxiv.org/abs/2606.02470)
