📄 Papers — ArXiv CS.AI
01

SHERLOC: Structured Diagnostic Localization for Code Repair Agents ArXiv

LLM agents spend ~50% of their budget locating faults before editing. SHERLOC shifts from file-level retrieval to actionable, structured diagnosis — producing specific location descriptions that directly feed repair. Score: 8/20 keywords.

02

Are We Ready For An Agent-Native Memory System? ArXiv

A survey of emergent memory architectures for LLM agents — from simple RAG to persistent data management with update, consolidation, and lifecycle governance. Asks whether the field needs a dedicated 'memory system' akin to database systems. Score: 7/20.

03

OpenThoughts-Agent: Data Recipes for Agentic Models ArXiv

Explores how to curate training data for broadly capable agentic models — going beyond single-benchmark approaches to build data recipes that generalise across SWE-bench, agent tasks, and tool use. Score: 4/20.

04

Grading the Grader: Lessons from Evaluating an Agentic Data Analysis System ArXiv

Agentic data analysis systems produce code, numbers, and diagnostics — making evaluation harder than single-turn LLM responses. Distinguishes genuine disagreement from evaluation noise in agent output assessment. Score: 3/20.

05

Grad Detect: Gradient-Based Hallucination Detection in LLMs ArXiv

A gradient-based method for detecting hallucinations in LLM outputs — leveraging internal model gradients rather than external verification, enabling real-time hallucination detection during inference. Score: 3/20.

06

Posterior Refinement: Fast Language Generation via Any-Order Flow Maps ArXiv

Non-autoregressive generation via any-order flow maps — models can recursively critique, erase, and regenerate arbitrary token subsets, addressing limitations of masked diffusion models. Score: 3/20.

07

Can Scale Save Us From Plasticity Loss in Large Language Models? ArXiv

Investigates whether simply scaling model size can overcome the loss of plasticity — the inability to learn new information after pre-training. A fundamental question for continual learning in LLMs. Score: 4/20.

08

Paying to Know: Micro-Transaction Markets for Verified Product Information in Agentic E-Commerce ArXiv

Proposes micro-payment markets for verified product information when autonomous agents shop — leveraging agent-native payment rails (x402, AP2) to buy ground-truth data instead of relying on recommender systems. Score: 4/20.
