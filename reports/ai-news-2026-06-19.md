## Papers — ArXiv CS.AI

### Multi-LCB: Extending LiveCodeBench to Multiple Programming Languages

LiveCodeBench (LCB) has become a widely adopted benchmark for evaluating LLMs on code-generation tasks. This work extends LCB to multiple programming languages beyond Python, curating competitive programming problems with fresh additions filtered by release date. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20517)

### UltraQuant: 4-bit KV Caching for Context-Heavy Agents

Context-heavy agents place unusual pressure on the KV cache: long prefixes are reused across many short turns. UltraQuant studies 4-bit KV-cache compression using TurboQuant-style methods, achieving significant memory savings with minimal quality degradation. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20474)

### Sovereign Execution Brokers: Enforcing Certificate-Bound Authority in Agentic Control Planes

Autonomous agents increasingly connect to cloud and data-control workflows, but production mutation authority should not reside inside non-deterministic reasoning processes. The paper proposes certificate-bound authority enforcement for agentic control planes — critical reading for anyone deploying AI agents in production. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20520)

### Your Mouse and Eyes Secretly Leak Your Preference: LLM Alignment using Implicit Feedback

To align LLMs, most methods collect explicit human feedback and train a reward model. This work proposes using implicit signals (mouse movements, eye tracking) to infer user preferences, reducing the need for explicit ratings. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20482)

### Efficient and Sound Probabilistic Verification for AI Agents

Securing AI agents operating in complex digital environments requires runtime monitoring with formal policies. This paper presents an efficient probabilistic verification approach extending Datalog-based enforcement, balancing soundness with computational feasibility. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20510)

### Calibration Without Comprehension: Diagnosing LLMs for Vulnerability Detection in Systems Software

Whether LLMs scoring well on vulnerability benchmarks genuinely reason about security or merely pattern-match remains unresolved. The authors present CWE-Trace, a framework built from 834 manually curated Linux kernel samples spanning 10 years of CVEs. **[arXiv Jun 2026]**

Sources: [arXiv](https://arxiv.org/abs/2606.20502)
