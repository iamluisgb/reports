01
AGL-SKILL: Coding Harnesses as Agentic Optimizers
Skill libraries for coding agents are usually improved by score-driven search over handcrafted prompts and workflows. This paper shows an unguided coding agent, set loose across five benchmarks, improves every target and beats published skill-optimisation methods. The harness itself becomes an editable surface the agent optimises. [agents, harnesses, self-improvement]

02
The Control-Flow Tax: Specialized Decision Routing for LLM Agent Workflows
Agents burn tokens deciding what to do next, not just doing it — routing accounts for 42.5% of baseline cost in their documentation workflow, and cheaper router models can trigger more expensive generator calls, so price cuts don't fix it. A specialised System 1 decision model (Jev) controlling finite actions alongside a generator (Sol) cuts mean cost 49.6% and elapsed time 33.2% on the initial task across 480 runs. [agent-architectures, cost, routing]
arXiv
03
LoomKV: Lossless KV Cache Compression from GPU Memory to SSD for LLM Serving
KV cache offloading to DRAM and SSD caps prefix reuse and concurrent long requests, and lossy compression silently changes outputs. LoomKV compresses losslessly at both tiers on an unmodified engine: BF16 KV at 0.71 of raw size across nine models, FP8 at 0.85–0.87, using a per-head two-level 3-bit code over the high bytes. [inference, kv-cache, serving]
arXiv
04
RepoClean: Evaluating Coding Agents on Repository-Level Obsolete Code Cleanup
Coding-agent benchmarks reward adding features; safely deleting dead code is under-evaluated despite being where agents can do real damage. RepoClean reconstructs 200 cleanup tasks from 34 Python repositories by re-introducing deleted code from real histories, so previously passing tests now fail and the agent must restore function without new development. [benchmarks, coding-agents, software-engineering]
arXiv
05
Measurement Artifacts in Trustworthiness Evaluations of Quantized Small Language Models
Quantisation papers routinely attribute benchmark deltas to quantisation, but instrument error that interacts with precision can manufacture or reverse the effect. Across eight sub-2B instruction-tuned models at three precisions, the 4-bit rise in harmful compliance is roughly half to two-thirds of what an uncorrected keyword detector reports, and cloze versus multiple-choice scoring disagree beyond their noise floor. A caution for anyone reading quantisation safety tables. [evaluation, quantization, safety]

Why It Matters
▸ The strongest signal in today's papers is that the model is no longer the expensive part of an agent. The Control-Flow Tax puts routing at 42.5% of workflow cost, AGL-SKILL shows the agent can optimise its own harness better than dedicated skill-search methods, and LoomKV attacks the KV cache — the plumbing that decides how many concurrent agent sessions you can serve. Stack that against the Lambda-sharded Qwen deployment running at 80× loss per token and the picture is consistent: the margin has moved from weights to orchestration, and most teams haven't re-audited their stack for it.
▸ Today is also a good day to distrust your instruments. The quantisation paper shows measurement error interacting with precision can invent or erase safety effects outright; the Anthropic distillation thread is a catalogue of how hard training-provenance evidence is to produce; and the Θ(n^2.25) matrix-multiplication claim — which would reprice every training run on earth — is a preprint awaiting exactly the kind of scrutiny these papers model. The habit worth copying: write the measured change as true change plus instrument error, then go find the interaction term.
▸ The agent-alignment essay (960 points) and the sandbox side-channel demonstration point the same direction from opposite ends. If agent behaviour follows the payer, and multi-tenant inference infrastructure leaks between supposedly isolated sandboxes, then the trust boundary is the inference provider, not the prompt — which strengthens the case for the local-compute camp (Songe, ternary Bonsai 2.5 at 27B) beyond mere cost. Watch whether harness-level work like AGL-SKILL gets paired with isolation guarantees; right now the optimisation and the containment live in different codebases.
