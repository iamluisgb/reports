Papers — ArXiv
01
ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows
LLM agents running a fixed SOP pay for a model call at every step of every run. ReTrace extracts the condition behind each tool call from the agent's own reasoning, merges conditions across logged runs into a rule document, and compiles it into an executable workflow where code, not an LLM, picks the next step. Validated on 79 procedures from a production platform; rule documents are portable across orchestration platforms. [agents, workflows, compilation]
arXiv
02
Crustify: Repository-Level Generation of Safe Rust Bindings with LLM Coverage-Guided Testing
Hand-written Rust bindings for C libraries hide unsafe code the compiler cannot check, so one mistake means undefined behaviour. Crustify schedules repository-level binding generation into dependency-ordered waves of concurrent agents, derives ownership and lifecycle contracts for every pointer, and validates each binding with coverage-guided equivalence and UB tests under sanitizers and Miri. Ships three supporting tools, including ffibox. [rust, ffi, agents]
arXiv
03
ExpertCrowd-SWE: Measuring Frontier Coding Agents on Expert-Authored Engineering Tasks
Coding-agent benchmarks lean on synthetic tickets that understate what maintainers actually refuse to merge. EC-SWE ships 100 expert-authored, multi-file change requests against pinned commits of real repositories, each with a sealed reference solution and a calibrated grader awarding partial credit. Median ticket is 148 words; median reference solution changes 471 lines across 87 projects and 11 languages. [benchmarks, coding-agents, evaluation]
arXiv
04
AgentScript-Eval: Benchmarking LLMs and Agents for Code Generation in an Enterprise DSL
Model coding ability is measured almost entirely on languages saturating the pretraining corpus; enterprise DSLs are neither abundant nor public. AgentScript-Eval grades 100 real tasks for AgentScript, the declarative DSL behind Salesforce's Agentforce, spanning agent authoring, debugging and optimisation. Zero-shot evaluation of five models quantifies how far general-purpose coding skill transfers to a guarded, specification-driven environment. [benchmarks, dsls, enterprise]
arXiv
05
WorkflowArena: Benchmarking Executable Workflow Orchestration in LLM-Based Multi-Agent Systems
Modern harnesses let the model instantiate workers and author the workflow coordinating them, making system structure a run-time capability rather than a developer decision. WorkflowArena isolates that capability with 145 long-horizon tasks across 8 professional domains, each specifying an initial workspace and an integrated deliverable built from interdependent parts. Existing benchmarks measure task completion; this one measures the orchestration itself. [multi-agent, orchestration, benchmarks]
arXiv
06
Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents
Distilled lessons from past trajectories can make agents fail on tasks they would otherwise solve, because lessons arrive detached from the evidence that produced them. WikiTrace links each stored lesson to a summary of its source trajectory so the agent can verify a lesson before applying it. The finding that trajectories usually still contain the evidence needed to catch an erroneous lesson turns memory from a liability into an auditable artifact. [memory, agents, reliability]

Why It Matters
▸ The centre of gravity in agent work has moved from model capability to the machinery around it. Five of today's six papers are about harnesses, graders, DSLs and orchestration rather than new models; the one memory paper is about verifying what an agent tells itself. That matches the news: GoogleChrome shipping prompt-ready rules to drag agents out of 2019 JavaScript, and a 458-comment fight over whether LLM code is structurally fragile, are both arguments about the harness, not the weights.
▸ The most quietly important idea today is ReTrace's: an agent's behaviour, once it repeats, should be compiled into a deterministic artifact and stop paying for inference at every step. That is the same instinct behind BPMN-to-agentic-workflow proposals and behind Anthropic's whiteboards and sheets — chat is a poor interface for repeatable process. Expect the 2026 pattern to be agents as compilers of themselves, with the LLM retained for the long tail, not the hot path.
▸ Verification is becoming the load-bearing wall. EC-SWE's calibrated graders with must-pass blockers, Crustify's Miri-and-sanitizer checks, AgentScript-Eval's execution grading and WikiTrace's evidence links all reject the premise that a plausible output is a correct one. Meanwhile VulnCheck now tracks CVEs Anthropic's models found and the Fireworks breach shows the AI supply chain as a routine incident vector — the same lesson from both directions: trust nothing you cannot re-run, re-derive or trace back to source.
