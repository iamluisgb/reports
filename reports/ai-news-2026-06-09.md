## Papers — ArXiv CS.AI

### SearchSwarm: Towards Delegation Intelligence in Agentic LLMs for Long-Horizon Deep Research

Large language models are increasingly expected to handle complex, long-horizon real-world tasks whose context demands can grow without bound, yet model context windows remain inherently finite. Recent efforts extend LLM reasoning via delegation — spawning sub-agents to explore in parallel. SearchSwarm formalizes this as delegation intelligence, enabling LLMs to recursively decompose and delegate research tasks across a swarm of specialized agents. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.09730)

### The Neutral Mask: How RLHF Provides Shallow Alignment while Leaving Partisan Structure Intact

The ambition behind alignment training is to make large language models safe and useful. The primary mechanism, reinforcement learning from human feedback (RLHF), shapes the behavior of deployed language models. This paper reveals that RLHF provides only shallow alignment — it masks partisan political structure in model outputs without fundamentally altering the underlying ideological priors. **[ArXiv CS.AI]**

Sources: [ArXiv CS.CL](https://arxiv.org/abs/2606.09735)

### OmniGameArena: A Unified UE5 Benchmark for VLM Game Agents

Vision-language model (VLM) agents are increasingly deployed in interactive game environments. Yet game benchmarks for VLM agents typically report a single first-attempt score per (agent, game) pair. OmniGameArena introduces a unified Unreal Engine 5 benchmark with improvement dynamics — measuring how agents learn and adapt across multiple attempts in photorealistic 3D environments. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.09826)

### FASE: Fast Adaptive Semantic Entropy for Code Quality

Multi-agent code generation offers a promising paradigm for autonomous software development by simulating the human software engineering lifecycle. However, system reliability remains hindered by LLM hallucinations and cascading errors. FASE introduces Fast Adaptive Semantic Entropy — a lightweight method to detect and filter low-quality code generations by measuring semantic uncertainty in the output distribution. **[ArXiv CS.AI]**

Sources: [ArXiv CS.SE](https://arxiv.org/abs/2606.09800)

### iOSWorld: A Benchmark for Personally Intelligent Phone Agents

A useful phone agent needs to be personally intelligent — reasoning over a user's identity, history, and preferences as they exist on the device. iOSWorld introduces a benchmark for personally intelligent phone agents that must navigate real iOS apps, access on-device data, and make context-aware decisions while respecting privacy boundaries. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.09764)

### Multi-Turn Evaluation of Deep Research Agents Under Process-Level Feedback

Existing benchmarks for deep research agents (DRAs) assess only single-shot outputs, ignoring a key question: can DRAs improve their reports when guided by feedback? This paper conducts a multi-turn evaluation of DRAs under process-level feedback, finding that iterative refinement with structured critique significantly improves report quality over single-shot generation. **[ArXiv CS.AI]**

Sources: [ArXiv CS.CL](https://arxiv.org/abs/2606.09748)

### SIGA: Self-Evolving Coding-Agent Adapters for Scientific Simulation

Advanced scientific simulators expose specialized input languages that turn simulation goals into executable configurations, but learning them can cost domain scientists hours to days. SIGA introduces self-evolving coding-agent adapters that learn simulator-specific languages through interaction, reducing the time to produce valid simulation configurations from hours to minutes. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.09774)

### Collaborative Human-Agent Protocol (CHAP)

Foundation models are moving from response generation into operational roles — planning across steps, calling tools, requesting human input, coordinating with other agents. CHAP proposes a standardized protocol for human-agent collaboration that defines interaction primitives, escalation paths, and shared state management for safe deployment of autonomous agents in production environments. **[ArXiv CS.AI]**

Sources: [ArXiv CS.AI](https://arxiv.org/abs/2606.09751)
