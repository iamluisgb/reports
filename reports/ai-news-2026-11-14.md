## Papers — ArXiv

### CapLite: Prompt-Injection Defense for Small Language Model Agents without Model-Written Security Artifacts

Enforcement defenses such as CaMeL, Progent and DRIFT ask the agent's own model to write the security artifact that code then enforces. Across 15 open-weight models — 13 of them between 1.7B and 12B parameters — those artifacts admit attacks on 14, 13 and 11 models respectively, and CaMeL's programs fail to run in up to 68% of episodes. CapLite derives its policy from tool schemas alone and commits write calls before any tool result is read, guaranteeing write integrity for small agents. **[prompt-injection, agent-security, enforcement]**

Sources: [arXiv](http://arxiv.org/abs/2611.17115v1)

### guardscope: Measuring Which Actions Runtime Controls Check in LLM Agent Systems

Agent gateways can only evaluate actions that cross their placement point, yet agents act through more paths than the tool-call channel; no prior work measured that coverage against ground truth. guardscope predicts which of an agent's 15 action paths a control can check from source, then runs a fixed workload across eight topology designs and classifies every executed action as checked, bypassed or prevented by reconciling decisions against kernel-level records. Control coverage becomes measurable rather than assumed. **[agent-security, runtime-controls, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2611.15223v1)

### Where LLM Agents Get Stuck Debugging Databases: Access More Than Reasoning

A field observation of Claude Code diagnosing eight database incidents in a production message-dispatch engine. In every incident whose root cause depended on runtime concurrency, the agent announced a cause, shipped a fix, and later walked it back — each wrong guess costing a deploy-and-observe cycle. The pervasive bottleneck was access to production state: live lock views, untruncated deadlock reports, read-only execution. The gap is tooling and permissions, not model capability. **[coding-agents, debugging, observability]**

Sources: [arXiv](http://arxiv.org/abs/2611.17304v1)

### MULTILOOP: Evolving Multi-Agent Harnesses for Complex Information-Seeking Tasks

Automated harness optimisation has so far targeted single-agent systems; multi-agent harnesses require editing how agents interact, not just how each behaves. On DeepSearchQA information-seeking tasks, a coding agent iteratively analyses traces, evaluates and edits the harness. With only 10 training samples, the evolved harness improves accuracy by 4.6% over the base. **[agents, harness-optimization, multi-agent]**

Sources: [arXiv](https://arxiv.org/abs/2611.15754v1)

### DISCERN: Preserve at Write, Resolve at Read for Persistent LLM-Agent Memory

Enterprise agents accumulate memory across sessions in which facts contradict and similarly named entities collide; the field treats this as a retrieval problem. On ENT-310, a 310-query benchmark with 100 unanswerable items, vanilla RAG already matches strong memory systems on recall — retention and currency are near-saturated at 0.93-0.98. What remains unsolved is resolution: which entity a query means, which time-state is current, and when to decline. DISCERN is built around resolve-at-read rather than better retrieval. **[agent-memory, rag, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2611.15729v1)

### Orbit: An Evidence-Grounded Benchmark for Evaluating LLMs on IT Operations Reasoning

ITOps benchmarks rarely show why a model fails, and an audit found template defects in about a tenth of Orbit's generated items before release. Five LLMs answer most multiple-choice questions correctly, between a third and just over half of open-ended items, and a minority of troubleshooting items even under a lenient root-cause rubric. Self-judging accepted answers to defective items, so every model is scored by one independent judge. **[benchmark, itops, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2611.15718v1)

## Why It Matters

-   The papers converge on a claim the model labs won't put on a slide: the model is no longer the bottleneck. DISCERN shows recall is essentially solved at 0.93-0.98 while resolution is unsolved; the database study finds access gaps, not reasoning errors, sink production debugging; MULTILOOP extracts 4.6% accuracy from editing the harness with ten training samples. Google shipping an Orchestrator model alongside Gemini 4 Hydrogen in Antigravity is the same bet at product scale — the differentiator now lives in the layer around the model.

-   The security papers attack the same assumption from the enforcement side: CapLite shows small models cannot write their own security artifacts without admitting attacks on 14 of 15 models, and guardscope shows gateway controls check far fewer action paths than deployments assume. That pairs uncomfortably with Anthropic's outage taking out app, CLI and API through one failure domain. Agent trust is being built as structure outside the model, and the structure has its own single points of failure.

-   If Nvidia really engineered a slice of its GPU demand through financed startups, the efficient-inference stack stops looking like a hobby and starts looking like a hedge. ggml reaching 1.0 is an API-stability commitment on exactly that layer, and Unsloth's per-layer quants are the practical expression of it. Meanwhile Brave settling Search API calls via x402 points to where agent economics are landing: per-request HTTP payments, not accounts — infrastructure that works whether or not the GPU revenue line is what the filings suggest.
