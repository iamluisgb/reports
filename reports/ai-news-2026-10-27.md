## Papers — ArXiv

### Free to Look, Free to Reason: Simple LLM Harnesses Outdiagnose Hand-Crafted Root Cause Analysis Agents

Published LLM root-cause-analysis agents impose hand-crafted investigation procedures, but nobody had checked whether that structure beats a capable model left alone. On RCAtlas — 90 validated cases from eight public datasets — three minimal harnesses (one evidence-package call, a SQL agent, Codex) hit PR@1 of 65-77% on mid-tier models, against 16-53% for five published agents and 6-39% for statistical and causal baselines. The simple harnesses won on every model where both families were run. **[agents, reliability, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2610.35767v1)

### Toward Evidence-Based Agentic Software Engineering

Agentic coding results conflate model and harness, so comparisons that change both together cannot attribute the effect. The authors annotated 325 experiments across 146 peer-reviewed papers from 2025-2026: only 15 report the exact harness version, 31 share execution traces for every session, and of 226 harness comparisons, 35 never varied the harness in isolation. The paper proposes reporting standards for agentic SE studies. **[methodology, evaluation, agents]**

Sources: [arXiv](https://arxiv.org/abs/2610.35348v1)

### Can Agentic Code Review Catch Vulnerabilities Before They Are Merged?

Existing security-review benchmarks derive the reviewed diff from its later fix, which leaks the answer. SecPRBench instead harvests, builds and validates 265 real bug-introducing commits from nine systems including Firefox, V8 and OpenSSL, then grades agentic review with LLM-as-a-judge. Across eight frontier models, recall spans 32.5% to 78.1% — a wide spread that says harness and model choice dominate, and that the ceiling is far from merge-blocking. **[security, agents, benchmark]**

Sources: [arXiv](https://arxiv.org/abs/2610.33509v1)

### Rivet: Utility-Preserving Context Control for Repository-Level Coding Agents

Repository-level agents select context by similarity, length or structural proximity, none of which measures whether the selected code contains the evidence the implementation actually depends on — a failure mode the authors call context utility dilution. Rivet scores candidate context by utility to the task and injects it accordingly. The framing matters more than the mechanism: relevance is not the same as dependency. **[context, coding-agents, retrieval]**

Sources: [arXiv](http://arxiv.org/abs/2610.34967v1)

### Navigating Epistemic Parity in LLM Agents: A Benchmark for Cross-Source Conflict Resolution Between Memory and Procedural Skills

Production agents inject episodic memory and procedural skill files into the same context region with no defined precedence, so the two can issue contradictory instructions nothing resolves. This benchmark instantiates 52 scenarios across a four-way taxonomy of contradictions — factual, format, procedural, permission — scored by deterministic checkers on tool-call payloads. It tests positional bias and whether an explicit precedence directive helps. **[memory, agents, evaluation]**

Sources: [arXiv](http://arxiv.org/abs/2610.33128v1)

### Agentic Algorithm Design: LLMs that Propose, Formalise, and Prove Runtime Bounds for Evolutionary Algorithms in Lean

LLM-guided heuristic design has been purely empirical; theorem provers prove given statements. This pipeline has an agent propose black-box optimisation algorithms, then define a potential function and prove drift bounds in Lean that guarantee expected runtime improvement over the baseline — with no empirical comparison anywhere in the loop. A first demonstration of design-plus-proof, not just proof-checking. **[formal-methods, agents, algorithms]**

Sources: [arXiv](http://arxiv.org/abs/2610.35595v1)

## Why It Matters

-   The day's strongest signal is that harness quality is now measurable and frequently decisive — and that the literature measuring it badly. The RCA paper shows minimal harnesses beating five published agent designs by double digits; SecPRBench shows a 45-point recall spread across frontier models on the same task. The 146-paper meta-study explains why nobody noticed: only 15 of 325 experiments pinned the harness version. If you are evaluating GPT-6.1 Terra this week, the model-against-model comparison is the least informative number you will collect.

-   Verification is fracturing into two tiers. OpenAI's claimed disproof of ETH and the Lean algorithm-design paper both point at machine-checked or peer-reviewed proof as the gold standard, while everything downstream — the KV cache leak in GLM-5.3, Cohere's open-weights findings, ChatGPT hallucinating a newsroom into a support desk — shows what happens when deployment outruns checking. The practical lesson for engineers is not philosophical: shared prefix caching and memory-plus-skill context stacks both fail silently, and both need deterministic tests on tool-call payloads, not vibes-based evals.

-   Context engineering is consolidating into a discipline with named failure modes. Rivet's context utility dilution, the epistemic parity benchmark's unresolved memory-skill conflicts and the RCA evidence-package result all converge on the same claim: what you put in the window, and with what precedence, matters more than how cleverly the agent reasons over it. Teams building on Terra or self-hosting open weights should spend the next sprint on context governance — precedence directives, utility-scored injection, conflict tests — rather than on prompt polish.
