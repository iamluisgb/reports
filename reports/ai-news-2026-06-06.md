## Papers — ArXiv CS.AI

### Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads

LLM agents are increasingly deployed on long-horizon tasks requiring sustained reasoning over extended interaction histories. Realizing this at scale requires agents to persistently store, retrieve, and update their own memory across sessions.

Sources: [ArXiv](https://arxiv.org/abs/2606.06448v1)

### MLEvolve: A Self-Evolving Framework for Automated ML Algorithm Discovery

LLM agents are increasingly applied to long-horizon tasks such as scientific discovery and machine learning engineering, where sustained self-evolution becomes a key capability. MLEvolve addresses inter-branch information isolation and memoryless session problems in existing MLE agents.

Sources: [ArXiv](https://arxiv.org/abs/2606.06473v1)

### Vortex: Efficient and Programmable Sparse Attention Serving for AI Agents

Sparse attention is becoming increasingly important for serving LLMs as generation lengths grow. Vortex enables deploying and evaluating new sparse attention algorithms at scale — lowering the engineering barrier for both researchers and AI agents exploring inference optimizations.

Sources: [ArXiv](https://arxiv.org/abs/2606.06453v1)

### RREDCoT: Segment-Level Reward Redistribution for Reasoning Models

Recent reasoning model advances are driven by RL fine-tuning via GRPO. RREDCoT introduces segment-level reward redistribution to improve Chain-of-Thought trace quality — addressing the credit assignment problem in long reasoning chains.

Sources: [ArXiv](https://arxiv.org/abs/2606.06475v1)

### You Only Index Once: Cross-Layer Sparse Attention with Shared Routing

Long-context inference in modern LLMs is constrained by decoding efficiency, especially in reasoning-heavy settings. This paper proposes cross-layer sparse attention with shared routing to reduce the efficiency-quality trade-off in sparse attention methods.

Sources: [ArXiv](https://arxiv.org/abs/2606.06467v1)

### Code2LoRA: Hypernetwork-Generated Adapters for Code LMs under Software Evolution

Code language models need repository-level context to resolve imports, APIs, and project conventions. Code2LoRA uses hypernetwork-generated LoRA adapters as a lightweight alternative to RAG or per-repository fine-tuning — scaling to hundreds of repos without retraining.

Sources: [ArXiv](https://arxiv.org/abs/2606.06492v1)
