# AI Reports

Static site of daily and special reports on artificial intelligence, generated by the
[Hermes Agent](https://github.com/iamluisgb/quiron) and published with GitHub Pages.

- **Live:** https://luisgonzalezbernal.com/reports/ (also https://iamluisgb.github.io/reports/)
- **Hosting:** GitHub Pages, `master` branch, served from repo root.

## Structure

```
index.html              Homepage — lists reports from reports.json (no GitHub API at runtime)
about.html              About page
styles.css              Shared styles for the index and every report
reports/                One HTML file per report
  ai-news-YYYY-MM-DD.html   Daily reports (filename starts with "ai-news-")
  <slug>.html               Special reports (any other .html)
reports.json            Generated manifest consumed by index.html
sitemap.xml             Generated sitemap
rss.xml                 Generated feed
scripts/generate_manifest.py   Builds the three generated files above
.github/workflows/build.yml    Runs the generator on every push to reports/
```

## How it works

The homepage used to query the GitHub Contents API from the browser on every load,
which is rate-limited to 60 requests/hour per IP and broke the site once exceeded.
Instead, `index.html` now fetches a static **`reports.json`** (same-origin, no limit).

`scripts/generate_manifest.py` derives all metadata from each report's HTML — title
(`<title>`), date (filename → `date-line` → first git commit date), subtitle, and a
**real reading time from the word count** — then writes `reports.json`, `sitemap.xml`
and `rss.xml`. A report is **daily** if its filename starts with `ai-news-`, otherwise
**special**.

## Adding a report

1. Drop the new HTML into `reports/` (dailies named `ai-news-YYYY-MM-DD.html`).
2. Commit and push to `master`.
3. The **Build manifest** workflow regenerates `reports.json`, `sitemap.xml` and
   `rss.xml` and commits them back. Nothing else to edit by hand.

To regenerate locally:

```bash
python3 scripts/generate_manifest.py
```

(No dependencies — Python 3 standard library only. Run from the repo root so git
history is available for dating special reports.)
